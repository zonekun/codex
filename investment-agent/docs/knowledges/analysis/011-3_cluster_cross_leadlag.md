## 仮説

残差相関クラスタ j で起きたショックが、クラスタ k に翌日以降遅れて伝播する。

011-1 のバリエーション1/2 は「同クラスタ内の情報拡散」だったが、本案は**クラスタを跨ぐ情報伝播**を許す。論文の「米国セクター → 日本セクター」と**完全に同型**であり、セクター = クラスタ、市場 = 時間帯 に置き換えたもの。

因果連鎖:
```
クラスタ A のリーダー銘柄で情報が顕在化（例: 半導体クラスタで TSMCサプライチェーン関連ショック）
  → クラスタ A の全銘柄に当日中に織り込まれる
    → 翌日以降、クラスタ B（例: 電子部品・素材クラスタ）に遅れて波及
      → クラスタ B の中小型銘柄でキャッチアップ
```

### 011-1 との構造的差異

011-1 のバリエーション1（自己リードラグ: 同銘柄の overnight→daytime）は「24時間以内に消滅する短寿命アルファ」だったため、個人投資家の1日ラグ制約で Sharpe が崩壊した（6.54→0.19）。

本案は**クラスタ間の情報伝播**を対象にしており、伝播に数日～数週間かかるならば週次リバランスでも捕捉可能。ただし、日本市場でクラスタ間情報拡散が数日持続するかは未検証。

## シグナル構造

### 論文との対応

| 論文の構造 | この応用 |
|---|---|
| A市場（米国セクター 11本） | **クラスタ j の代表リターン**（j = 1,...,20）|
| B市場（日本セクター 17本） | **クラスタ k の代表リターン**（k = 1,...,20）|
| V₀ = [グローバル, 国スプレッド, シクリカル/ディフェンシブ] | V₀ = [市場全体, サイズスプレッド, シクリカル/ディフェンシブ]（クラスタ間の経済直観ベース）|
| 結合相関 28×28 | 結合相関 40×40（20クラスタ × 2タイムスロット）|
| B_t = V_J V_Uᵀ (17×11) | **B_t = V_k,t V_j,tᵀ (20×20)**、rank ≤ K |

### 低ランク伝播行列 B_t

```
B_t^(K) = V_follow,t^(K) @ V_lead,t^(K).T  ∈ ℝ^(20×20)
```

- V_lead: 先行クラスタ側の固有ベクトル（K次元）
- V_follow: 追随クラスタ側の固有ベクトル（K次元）
- rank(B_t) ≤ K
- B_t の (k,j) 成分 = 「クラスタ j のショックがクラスタ k にどの程度伝播するか」の時変係数

### 実装の2段階

**ステップ1: クラスタ代表リターンの構築**

各クラスタ j の代表リターン r_j,t を構成銘柄の等ウェイト平均（or 時価総額加重）で作る。20クラスタ × T日 の時系列。

**ステップ2: クロスリードラグのシグナル生成**

日 t-1 の 20 クラスタ代表リターンベクトル z_lead,t-1 を低ランク行列 B_t で写像して、日 t の 20 クラスタ予測ベクトル ẑ_follow,t を得る:

```
ẑ_follow,t = B_t^(K) @ z_lead,t-1
```

ẑ_follow,t のクラスタ k 成分が正（大きい）なら、クラスタ k の銘柄をロング。

### 個別銘柄への展開

クラスタレベルのシグナル ẑ_follow,t を個別銘柄に割り当てるには:
- クラスタ k に属する銘柄 i は全て同じシグナル ẑ_follow,t[k] を受け取る
- クラスタ k 内でさらに流動性 or 前日リターンの遅延度で重み付け可能（応用）
- ロング候補 = シグナル上位のクラスタに属する銘柄群

## 012 バリエーション1/2 との比較

| 比較軸 | Var.1（011-1 自己リードラグ） | Var.2（011-1 クラスタ内クロス） | **Var.3（本案: クラスタ間クロス）** |
|---|---|---|---|
| 情報源→対象 | 銘柄 i → 銘柄 i | クラスタ内他銘柄 → 銘柄 i | **クラスタ j → クラスタ k** |
| アルファの持続時間 | 24時間以内（消滅確認済み） | 24時間以内（推定） | **数日～数週間（仮説、未検証）** |
| 個人での実装可能性 | ❌ FAIL（Sharpe 0.19） | ❌ 推定 FAIL（011-1 と同じ制約） | **△ 未検証（持続時間次第）** |
| 次元 | N×N（921×921） | N×N | **20×20（クラスタ数）** |
| V₀ の活用度 | 間接（C₀ のみ） | 直接 | **最も直接** |

### 本案の優位点

1. **次元が劇的に小さい**: 921×921 ではなく 20×20 → 固有分解が安定、推定誤差が小さい
2. **論文と最も同型**: 米国11セクター→日本17セクターの構造をそのまま踏襲
3. **クラスタが年次で変わる**: 2020年と2025年でクラスタの意味が異なる → 年次ローリングで時変構造を捕捉
4. **残差相関クラスタは業種33と異なるグルーピング**: 「東証33業種では見えない隠れた関係」をシグナル生成に初めて使う

## 着手時期と前提条件

**011-2 の Pass 1 結果を見てから判断する**。理由:

1. 011-2 が成功した場合: 「日足ベースの情報拡散は数日持続する」ことが確認される → 011-3 も期待できる
