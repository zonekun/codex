## 概要

「SKEW高水準 + VIX低水準 + Fear&Greed強欲」の3条件が揃うと、
60日後に大暴落（-10%超）が発生する確率がベースラインの **2.2倍（6.8% → 14.7%）** に上昇する。
ショート戦略ではなく **リスク管理・ヘッジ判断の補助指標** として使用する。

| SP500 | 価格ベース（欠損はffill） |

## 使用アルゴリズム

- **シグナル定義**（AND条件）:
  - SKEW ≥ 142.5（全期間90パーセンタイル）
  - VIX ≤ 14.3（全期間25パーセンタイル）
  - Fear & Greed ≥ 70（強欲ゾーン）
- **検定**: Welch's t検定（シグナル発生日の60日後リターン vs 全期間ベースライン）
- **選択理由**: 単純な前向きリターン分布の比較。ラグを5/10/20/30/45/60/90/120日と総当たりし、最も有意なラグを採用

### ラグ別 p 値（3条件シグナル、N=75件）

| ラグ | 平均リターン | 中央値 | 下落率 | ベースライン | p値 | 判定 |
|-----|------------|--------|--------|------------|-----|-----|
| 5日 | +0.43% | +0.38% | 31% | +0.17% | 0.36 | × |
| 10日 | +0.89% | +0.95% | 15% | +0.34% | 0.15 | × |
| 20日 | +1.21% | +2.38% | 23% | +0.67% | 0.31 | × |
| 30日 | +1.67% | +2.74% | 31% | +1.00% | 0.30 | × |
| 45日 | +0.72% | +1.30% | 37% | +1.48% | 0.33 | × |
| **60日** | **-1.62%** | +2.53% | 40% | +1.95% | **0.0001** | **★★有意** |
| 90日 | +2.48% | +2.09% | 31% | +2.90% | 0.70 | × |

### リターン分布（60日後）

```
-20%超下落:  7件（2019年12月 → COVID暴落）
-10〜-20%:   4件
 -5〜-10%:   9件
  0〜 -5%:  10件
  0〜 +5%:  31件  ← 多数派（60%は普通に上昇）
 +5〜+10%:  14件
```

### 大暴落（-10%超）発生率

| | 発生率 |
|--|--------|
| シグナル時 | **14.7%**（11/75件） |
| ベースライン | 6.8% |
| **倍率** | **2.2倍** |

### 判定と理由

**ANALYZED_PASS（条件付き）**

p=0.0001 で統計的有意。ただし以下の留意点あり:
- 平均-1.62% vs 中央値+2.53% の乖離が大きい → 少数の大暴落事例に平均が引っ張られている
- 大暴落11件のうち7件が2019年12月（→ 2020年COVID）に集中。実質ユニークイベントは2件程度
- 60日ラグのみ有意（前後は非有意）→ 過学習リスクあり
- BACKTEST_PASSには達しない（売買ルールが定義できない）

## 実用的な使い方

### 現在の市場状況チェック（手動）

```python
import pandas as pd
df = pd.read_csv('data/csv/bond_history.csv', parse_dates=['DATE'])
df = df.sort_values('DATE').reset_index(drop=True)
for c in ['SP500','VIX','SKEW','FEAR_GREED']:
    df[c] = df[c].ffill()

SKEW_TH = df['SKEW'].quantile(0.90)   # 142.5
VIX_LOW = df['VIX'].quantile(0.25)    # 14.3
FG_HIGH = 70

latest = df.iloc[-1]
print(f'日付: {latest[\"DATE\"].date()}')
print(f'SKEW={latest[\"SKEW\"]:.1f} (≥{SKEW_TH:.1f}?) VIX={latest[\"VIX\"]:.1f} (≤{VIX_LOW:.1f}?) F&G={latest[\"FEAR_GREED\"]:.0f} (≥{FG_HIGH}?)')
signal = (latest['SKEW'] >= SKEW_TH) and (latest['VIX'] <= VIX_LOW) and (latest['FEAR_GREED'] >= FG_HIGH)
print('シグナル:', '🔴 発火中（大暴落リスク2.2倍）' if signal else '🟢 非発火')
```

### 運用ルール（案）

- 3条件全発火 → ロングポジションのサイズ縮小 or プット購入を検討
- あくまで補助情報。単独でポジション変更の根拠にしない
