## 仮説

EDINET大量保有報告書の異常遅延提出/古い報告書への訂正 → 保有関係の整理中 → M&A/TOB/MBO準備の兆候 → TOB発表時に買収プレミアムで株価急騰

**複合条件で精度向上:**
遅延報告 + 低PBR（資産価値 > 時価総額）+ 特別損失計上（業績悪化）+ 配当未定/減配 + 経営陣交代 → TOB候補としての蓋然性が高まる

**実例（8289 Olympicグループ）:**
- 2026/03/21: カネヨシの訂正報告書検知（保有割合 27.31%→31.45%）
- 2026/04/01: ストップ高（「選択」誌の身売り記事）
- 条件: PBR 0.54、特損638百万、配当未定、会長逝去→社長交代、23区内資産大

## 考察: なぜ効かなかったか

遅延報告銘柄はTOB候補として統計的に有意（ヒット率9.8% vs ベース~2%）だが、
**TOBが起きなかった90%の銘柄の株価劣後がTOBプレミアムを打ち消す**。
遅延報告はTOBの「必要条件の一つ」であり「十分条件」ではない。

記事著者が成功した理由は、遅延報告を「スクリーニングの入口」として使い、
**個別の定性分析（会長逝去・配当未定・不動産含み益等）で絞り込んだ上で集中投資**していたため。
機械的なロングでは再現できない。

### 判定

- **SCORE≥10 × アクティビスト**: CARは全期間で大幅プラス（250D +37.2%、勝率66.7%）。ただし**N=7（3銘柄）で統計的有意性なし**。参考値として有望だが単独戦略としては不十分
- **SCORE≥8 × アクティビスト**: N=22（11銘柄）でやや実用的。250D +13.76%、勝率65.0%は有望。中央値も+16.22%でプラス
- **高スコア×非アクティビスト**: 全期間で大幅マイナス（250D -15〜-24%）。ファンダメンタルが弱い（=高スコア）のにアクティビストがいない銘柄は純粋に業績低迷で株価が下がる
- **TOB発生は高スコア群で0件**: 高スコア×アクティビストの超過リターンはTOBプレミアムではなく、アクティビストによるガバナンス改善・再編圧力が株価を押し上げるメカニズム

### 考察

1. **アクティビストが支配的ファクター**: スコアの高低よりもアクティビスト有無が圧倒的にリターンを分ける。非activist高スコア = 最悪の投資対象
2. **複合条件は「ファンダ弱+触媒あり」の論理**: 低PBR・特損・配当未定（=割安放置）+ アクティビスト（=変革触媒）の組み合わせが価値実現を促す
3. **サンプルサイズの制約**: SCORE≥10×activistはN=7。外挿には慎重を要する。SCORE≥8なら N=22 で傾向は読み取れるが統計検定には不十分
4. **遅延報告そのものの情報価値は限定的**: 真の価値はアクティビストの存在検知。遅延報告はスクリーニング入口として機能するが、単独シグナルとしては無力（BACKTEST_FAIL確定）

## 方向性A: ML統合（2026-04-29）— 不発

遅延報告特徴量（`has_delay_report`, `delay_filing_count`, `max_delay_days`）を007 TOB予測RFモデル（22→25特徴量）に追加して再学習。

### 結果

| 指標 | 旧モデル(22特徴量) | 新モデル(25特徴量) | 差分 |
|------|:-:|:-:|:-:|
| ROC-AUC平均 | **0.781** | 0.752 | -0.029 |
| PR-AUC平均 | **0.104** | 0.079 | -0.025 |
| 2025 Top5%ヒット率 | **20.0%** | 14.3% | -5.7pp |

### 判定: 不発 — モデルに不採用（旧版に復元済み）

**原因**:
- 遅延報告は全~3,900銘柄中~1,038銘柄にしか存在（大半が0）→ スパースすぎてノイズ
- feature importance全年Top10圏外 → モデルが情報として活用していない
- `has_activist`（既存特徴量）が遅延報告の情報を既に吸収。遅延報告はアクティビスト活動の「下流の兆候」であり、上流の`has_activist`で十分

**追試: 1000日以上遅延フィルタ（24特徴量）**:
- 245銘柄/476件に絞って再テスト → ROC-AUC 0.754、PR-AUC 0.077、Top5% 13.6%
- 旧モデル（ROC 0.781、PR 0.104、Top5% 20.0%）にまだ劣る
- 1000日フィルタでもfeature importance Top10圏外、改善なし
- **結論**: 遅延日数の閾値を上げても本質的にノイズ。train_rf.pyは旧版（22特徴量）に復元
