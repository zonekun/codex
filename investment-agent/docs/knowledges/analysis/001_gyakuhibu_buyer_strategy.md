# 逆日歩狙いの買方投資

**カテゴリ**: analysis
**作成日**: プロジェクト開始時
**ステータス**: 要検証
**関連ファイル**: reference_code/gyakuhibu_rank.py, reference_code/cross_section_pbr.py

## 概要
品貸料（逆日歩）発生銘柄の買方ポジションで超過リターンを狙える仮説。YouTubeライブ配信チャットが着想元。

## 仮説

品貸料（逆日歩）が発生している銘柄は、空売り勢の買い戻し圧力により
株価が上昇する傾向があり、信用買い方は逆日歩収入に加えて
株価上昇益を得られるのではないか。

## 検証アプローチ

### 1. ランク別分析
- 逆日歩の大きさ（高/中/低/なし）でランク分け
- 各ランクの銘柄群のフォワードリターンを比較
- 参考: `reference_code/gyakuhibu_rank.py`

### 2. クロスセクション分析（逆日歩 × PBR）
- PBR低位（割安）× 品貸料なし → 上がりやすい傾向の検証
- PBR高位 × 逆日歩高 → 期待値はどうか
- 参考: `reference_code/cross_section_pbr.py`

### 3. セクター別スプレッド分析
- 品貸料発生銘柄 vs 非発生銘柄のリターンスプレッドをセクター別に計算
- 銀行・金融・不動産でスプレッドが大きい傾向
- ただし「逆日歩を実際に払って信用買いして取れるか」は別問題
- 参考: `reference_code/sector_spread.py`

## 必要データ
- 日証金: 逆日歩（品貸料）ヒストリカルデータ → `skills/nisshokin_fetch.md`
- J-Quants or yfinance: 株価データ
- PBRデータ（事前クレンジング推奨 → `data/cleansed/`）
- セクター分類マスタ

## 備考
- 逆日歩データは日証金から1銘柄ずつ期間指定で取得する必要がある（手間大）
- スクレイピングスキルで自動化済み: `skills/nisshokin_fetch.md`
- スプレッドが開いていても、実際の取引コスト（品貸料）を考慮すると収益性は不明
