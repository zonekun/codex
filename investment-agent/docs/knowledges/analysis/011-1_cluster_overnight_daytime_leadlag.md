## 背景: 前場→後場案からの設計変更

当初は「**前場（09:00–11:30）→ 後場（12:30–15:00）**」の非同期性を活用する設計で企画した（本ファイル末尾「将来の宿題」参照）。しかし J-Quants API 仕様調査（2026-04-11実施）の結果:

| 選択肢 | 可否 |
|---|---|
| 前場四本値API (`eq-bars-daily-am`) | **Premium契約必要、かつ直近データのみ（ヒストリカル提供なし）** |
| 分足API (`eq-bars-minute`) | アドオン契約必要、**最大2年前まで**（論文レベルのバックテストには不足、かつ overkill） |
| 日足OHLCで前場/後場を区別 | Open/Close しか無いので**不可能** |

→ 現契約（Standard）かつ追加契約なしでは **前場/後場ヒストリカルデータは取得不可**。

**設計変更**: 論文の核心（非同期市場 × 低ランク共通因子 × 事前情報縮約）を維持したまま、「前場/後場」を「**オーバーナイト（15:00引け→翌09:00寄付）/ 日中（09:00寄付→15:00引け）**」に置き換える。これは Akbas, Boehmer, Jiang, Koch (2022) "Overnight returns, daytime reversals, and future stock returns" JFE（原論文 references[17]）の**日本版 + クラスタ拡張**にあたる。

既存BQ `STOCK.STOCK_PRICE_JQUANTS` の ADJ_OPEN / ADJ_CLOSE で完全にカバーでき、**2016年以降の10年分**を即利用できる。

## 核心アイデア: 残差相関クラスタを V₀ に埋め込む

論文の V₀ は [グローバル / 国スプレッド / シクリカル-ディフェンシブ] の**たった3本**の事前ベクトルでした。これを**既存クラスタリングで得た 20 個のクラスタ所属ダミー**に差し替えます。

```
V₀ = [c₁, c₂, ..., c₂₀]   (各 c_k は N 次元、cluster k 所属銘柄=1, それ以外=0、直交化済み)
```

この V₀ は論文の3本と比べて**事前情報量が圧倒的に多い**。しかも「東証33業種では見えない隠れた連動構造」を既に内包している。λ=0.9 の縮約で「隠れた仲間同士の共通ショック」が強調されます。

## オーバーナイト→日中 × クラスタの組合せ

| 論文の構造 | この応用 |
|---|---|
| A市場（米国、先に閉まる） | **オーバーナイト**（前日15:00引け〜当日09:00寄付） |
| B市場（日本、後に開く） | **日中**（当日09:00寄付〜15:00引け） |
| 情報セット z_U,t | 銘柄別オーバーナイトリターン `log(Open_t / Close_{t-1})`（400–500銘柄） |
| 予測対象 z_J,t+1 | 同銘柄 or 他銘柄の日中リターン `log(Close_t / Open_t)` |
| V₀ = 3本（経済直観） | **V₀ = 20本（クラスタ所属ダミー）** |
| 結合相関 28×28 | 結合相関 N×N (N≒500) |
| B_t = V_J V_Uᵀ | B_t = V_DAY,t V_ON,tᵀ（低ランク 20次元） |

非同期性は「取引時間外（18時間）」の情報ギャップに置き換わる。この期間中に織り込まれる情報源:
- 米国市場の引け（S&P500, ナスダック, セクターETF）
- 大証ナイト先物の夜間動向
- 企業の決算開示（15:30以降に集中）
- アジア市場の早朝動向
- マクロ経済ニュース（FOMC, 雇用統計等）

これらが翌朝09:00の寄付価格に先に織り込まれ、**日中の取引でクラスタ内の遅延銘柄に波及**する、というのがこの戦略の経済直観。

## 3つのバリエーション（弱い順に強い）

### バリエーション1: 自己リードラグ（オーバーナイトモメンタムの純化）

同じ銘柄 i のオーバーナイト → 日中 を、クラスタ情報で構造化して予測。
- 利点: データが揃えば即実装
- 欠点: 単純な「寄付から引けへのモメンタム/リバーサル」と区別しにくい
- 留意: Akbas et al. (2022) は**daytime reversals**を報告しているので、シグナルの符号は負（リバーサル）になる可能性がある

### バリエーション2: クラスタ内クロス予測 ★本命

**銘柄 i の日中 ← 同クラスタ内の「他銘柄」のオーバーナイトの共通成分**

これが Hou (2007) の情報拡散を、業種分類ではなく**残差相関クラスタ**で焼き直すアイデア。既存クラスタリングが発見した「隠れた仲間」間で、先に動く銘柄→遅れて動く銘柄への拡散を捕捉。

- **何故効くはず**: 残差相関クラスタは既に「業種で説明できない隠れた連動」を捕捉しているので、同クラスタ内は情報を共有している可能性が高い。クラスタ内で**流動性が高く機関投資家が寄付で織り込む銘柄**から**中小型・個人投資家中心で反応が遅い銘柄**への日中キャッチアップが起きる
- **V₀ 設計**: 20本のクラスタダミー。低ランク K=20 固有分解
- **シグナル**: 銘柄 i の日中予測 = (他クラスタメンバーのオーバーナイト共通成分) × (クラスタ内 i のローディング)

### バリエーション3: クラスタ間クロスローディング ★最も論文に近い

**クラスタ j のオーバーナイト → クラスタ k の日中** の矢印も許す。つまり「クラスタ A で起きたオーバーナイトショックがクラスタ B に日中伝播する」構造を低ランク PCA で自動抽出。

- 論文の「米国セクター→日本セクター」と**完全に同型**（セクター = クラスタ、市場 = 時間帯）
- B_t = V_DAY,t V_ON,tᵀ は 500×500 行列だが rank ≤ 20
- クラスタ j の意味は毎年変わるので、年次ローリング

## さらに面白い派生: C₀ の直接利用

論文は λ=0.9 で C_t^reg = 0.1 C_t + 0.9 C₀ を作り、C₀ は事前固有ベクトルから逆合成していた。このアプローチでは:

**C₀ = 既存の `residual_corr_YYYY.csv` そのものを使える**

これが効く直感: 残差相関行列はすでに「業種・サイズ・市場を除いた純粋な銘柄間連動」を捉えている。λ=0.9 で短ウィンドウノイズに引きずられず、長期構造に縮約する理想的なターゲット。論文の「経済直観から V₀ を手で作る」工程を完全にバイパスできる。

## データ構成（BQクエリで即完結）

```sql
-- オーバーナイトリターン: log(今日のOpen / 前日のClose)
-- 日中リターン: log(今日のClose / 今日のOpen)
WITH base AS (
  SELECT
    TICKER,
    DATE,
    ADJ_OPEN,
    ADJ_CLOSE,
    LAG(ADJ_CLOSE) OVER (PARTITION BY TICKER ORDER BY DATE) AS PREV_ADJ_CLOSE
  FROM `gmailpj-357912.STOCK.STOCK_PRICE_JQUANTS`
  WHERE DATE BETWEEN '2016-04-01' AND '2026-04-01'
)
SELECT
  TICKER,
  DATE,
  LN(ADJ_OPEN / PREV_ADJ_CLOSE) AS overnight_ret,
  LN(ADJ_CLOSE / ADJ_OPEN)      AS daytime_ret
FROM base
WHERE PREV_ADJ_CLOSE IS NOT NULL
  AND ADJ_OPEN > 0
  AND ADJ_CLOSE > 0
```

※ 実際のカラム名は `data_catalog.md` で要確認（ADJ_OPEN / ADJ_CLOSE があるか、別名か）。

## 執行タイミング（決定事項）

### 採用: オプションA（寄引戦略）★個人投資家向けの最終形

個人投資家は寄付後すぐにシグナル計算→数分以内に手動発注は不可能なため、以下の寄引パターンを採用する:

- **前日 15:00 以降**: 当日分のデータ確定後にシグナル計算
- **前日夜〜翌日寄付前**: 翌日の**寄成注文**を証券会社サイトで予約
- **翌日 09:00 寄付**: 自動執行でエントリー
- **翌日 15:00 引け**: 引け成行で手仕舞い

ただしこのパターンでは「翌日09:00のOpen」がまだ確定していない時点で注文を出すため、**シグナルは「前日Closeまでの情報」だけを使って構築する必要がある**。具体的には:
- 使える情報源 A: 前日までの overnight リターン (log(open_{t-1}/close_{t-2}) と log(close_{t-1}/open_{t-1}) の組合せ)
- 予測対象 B: 翌日の寄付→引けの日中リターン（= log(close_t/open_t)）

原案は「当日overnight → 当日daytime」だったが、**個人投資家では当日overnightが確定した瞬間（9:00）に発注できないため実装不可**。したがって 1日ラグをずらして「前日情報 → 翌日日中」の形に変更する。シグナル強度は低下する可能性があるが、これが執行可能な唯一の形。

### 次案: オプションB（ザラ場固定時刻執行）

オプションA で期待リターンが不十分な場合の次の選択肢:

- **ザラ場内の特定時刻（例: 毎日 10:00 or 13:00）**でシグナル計算→手動発注
- **09:00 寄付後**: オーバーナイトリターン確定、シグナル計算に使える
- **ザラ場中の固定時刻**: エントリー
- **15:00 引け**: 引け成行で手仕舞い

利点: 当日overnight情報をシグナルに使える（オプションA より情報量が多い）
欠点: 毎日特定時刻にマニュアル操作が必要、定時勤務との両立が難しい

### ポジション方向: ロングオンリー（決定）

**ショートは採用しない**。理由:
- 個人の空売りは一般信用で銘柄が限られる
- 貸株料（年1-4%）が利回りを圧迫
- 逆日歩リスクあり
- 執行の複雑性が大幅に増す

そのため:
- シグナル上位のみで**トップ q 銘柄をロング**
- 市場中立化したい場合は**インバースETF（1357日経Dインバ等）で全体ショート**を検討
- 単純なロングオンリー版で期待リターンが十分なら、市場中立化すら不要

### 銘柄数の現実的制約

トップ q=0.3（数百銘柄）は最小単元株の制約で実装不可能。個人投資家の実装可能範囲:

- 資金 500 万円 → 上位 20 銘柄程度（q ≈ 0.02）
- 資金 1000 万円 → 上位 30-40 銘柄（q ≈ 0.04）
- 資金 3000 万円 → 上位 50-80 銘柄（q ≈ 0.06-0.08）

バックテストでは **q=0.05 と q=0.10 の 2 水準**で再評価することを推奨。

## 懸念点

1. **日中リターンの執行コスト**: 寄付直後の建玉はスリッページが大きい。実務では寄前成行 or VWAP 執行に近いロジックが必要
2. **クラスタの安定性**: `clusters_YYYY.csv` は年次更新。年末年始でクラスタラベルが不連続に変わるタイミングでシグナルがジャンプする可能性 → ローリング更新化を検討
3. **オーバーナイトリターンの左偏歪**: ギャップダウンは決算ネガティブサプライズで発生しやすく、外れ値の影響を受けやすい → winsorize 必須
4. **同銘柄の自己自明性**: バリエーション1 は寄付 → 引け のモメンタム/リバーサルと区別しづらい。バリエーション2/3 が本命

## 将来の宿題: 前場 → 後場 バージョン（本命の復活形）

本アプローチは「オーバーナイト→日中」という**18時間の非同期性**を使っているが、**本命は「前場→後場」の1時間昼休みギャップ**である。理由:

1. **情報の純度**: 前場の値動きは「取引時間中に織り込まれた情報」なので、夜間ノイズ（マクロ・米国市場・決算開示）がほとんど含まれず、**純粋な日本市場内の情報拡散**だけを捉えられる
2. **クラスタ内情報拡散との親和性**: 同クラスタ内で「機関投資家が午前に動かした銘柄→個人投資家の午後のキャッチアップ」という経路が最もクリーン
3. **昼休み1時間は情報源が限定**: CMEミニ日経先物・昼のニュース程度。これに対する日本株の反応は論文と同型の非同期構造

### 必要なデータは「前場終値 MC」1点だけ

分足は overkill。論文構造に必要な前場/後場リターンは以下の定義で済む:

```
前場リターン = log(MC / Open)     ← Open(9:00) と MC(11:30)
後場リターン = log(Close / MC)    ← MC(11:30) と Close(15:00)
```

既存日足 OHLC で Open(9:00) と Close(15:00) は持っているので、**銘柄×日付ごとに 前場終値 MC 1個**だけ追加すれば足りる。昼休み12:30の寄付ギャップは後場リターンに吸収されるが経済的にはほぼ同じ非同期性を捕捉できる。

### 失敗の構造的解釈

**「overnight→daytime リバーサル」は 24時間以内に消える短寿命アルファ**。同日 09:00 のOpen確定後から同日 15:00 引けまでの逆行を捕捉する論文の効果は、**個人投資家の執行枠組み（前日夜に寄成予約、翌日寄付エントリー）では原理的に捕捉できない**。シグナルを1日ずらすだけで Sharpe が 6.54 → 0.42（グロス）に崩壊した。これはパラメータチューニングで救える問題ではなく、**執行時間帯の制約による構造的な死**。

### Pass 2 非推奨の理由

- Variation 2（クラスタ内クロス予測）も同じ1日ラグ問題を共有するため、理論最大でも Sharpe 0.4 程度
- 期間拡大・Carhart4 α は微弱シグナルの詳細検定ツールであり、構造的に死んでいるシグナルには使っても無駄
- 費用対効果が成立しない

## ステータス (最終)

**ANALYZED_FAIL（RETIRED）**。個人投資家では実装不可能と確定。

### 将来の可能性（復活条件）

1. **intraday 高頻度執行の枠組みが整った場合**: プロ・HFT業者レベルで 09:00-09:05 のシグナル計算→即発注が可能なら元論文の効果を捕捉できる可能性あり。ただし本プロジェクトのスコープ外
2. **前場/後場データが入手できた場合**: 本ファイル下部の「将来の宿題」参照。前場→後場の 1時間ラグなら 24時間より短いため、シグナルが生き残る可能性がある
3. **別の非同期性を見つけた場合**: 「取引時間帯の非同期性 × 低ランク共通因子 × 事前情報縮約」の枠組み自体は死んでいない。別のペアリング（例: 013 の大→小サイズリードラグ）で再利用する
