## 仮説（論文の核を抽象化）

論文そのものではなく、**論文の構造を再利用する発想**を保管する。論文の核心は次の3点セット:

1. **非同期市場**: 情報源 A と投資対象 B の取引時間帯がズレており、A 確定後 B が開く
2. **低ランク共通ファクター**: A と B は少数の共通ショックで動く
3. **事前情報による縮約推定**: 短ウィンドウ推定の不安定さを、経済的に意味ある事前部分空間 V₀ への縮約（λ=0.9 の Ledoit-Wolf 型シュリンク）で安定化

> 因果連鎖（一般形）:
> A市場の共通ショック g_t → A のセクターリターン（確定） → B の翌ザラ場 Open-to-Close に波及 → B側でロングショート収益

**米国 → 日本 は論文で検証済みなので再現するだけ**。本ファイルは「A と B をどう組み替えれば未探索の収益源を掘れるか」の候補集。

## 分析の方向性

**ANALYZING フェーズに入る際のフロー（上記どの応用を選んでも共通）**:

1. A・B それぞれの日次リターンを取得、共通営業日に揃える
2. 結合相関行列 C_t を L=60 窓で計算（論文準拠）
3. V₀（応用ごとに異なる経済的事前ベクトル）を構築
4. Ledoit-Wolf 縮約 C_t^reg = 0.1·C_t + 0.9·C₀ の固有分解、K=3 低ランク射影
5. B_t = V_B V_Aᵀ で B 側シグナルを生成、上位30%ロング/下位30%ショート
6. 論文と同じ評価（AR, RISK, R/R, MDD, Carhart4 α+Newey-West）
7. ベースライン: 単純モメンタム、λ=0 の PCA_PLAIN、ナイーブ相関回帰

## 考察: なぜこの拡張に意味があるか

論文の核心は「米国」そのものではなく、**「事前構造を押し付けた低ランク縮約」が短ウィンドウで働く**点。同じ数学的構造は、情報源と投資対象のどんなペアにも適用可能で、λ の大きさ（事前情報の信頼度）と V₀ の設計（経済直観の強さ）が勝負を決める。

つまり **V₀ が経済的に妥当なケースほど、論文手法の優位性が出る** と期待できる。為替→セクター（C-2）や金利→金融（C-3）のような事前構造が極めて明快なケースは、米日リードラグより縮約効果が大きい可能性がある。
