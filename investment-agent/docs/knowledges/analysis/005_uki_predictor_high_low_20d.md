## 概要

XGBRegressorを使って**20営業日後の最高値・最安値の変化率**を予測するモデル。
テクニカル（約60個）＋ファンダメンタルズ（約130個）の計約190個の特徴量を使用。
決算開示後の市場織り込みラグを利用し、20日間の「浮き（UKI）」を先読みするアプローチ。

---

## 投資仮説

### 仮説①：財務開示後の価格調整ラグ
- 決算開示直後は市場がまだ完全に反映していない
- 20営業日かけて段階的に価格が調整される
- その調整過程の「幅」を先読みできれば優位性あり

### 仮説②：決算サプライズ × テクニカルの複合効果
- 単純なファンダスコアより、テクニカル（変動性・流動性）と組み合わせると予測精度が上がる
- サプライズの大きさ（m_sales等）が実現リターンに比例する傾向

### 仮説③：流動性フィルターの有効性
- 市場インパクト（MI = range / (出来高×終値)）が高い＝流動性が低い銘柄は価格調整が遅い
- 予測スコアが高くても低流動性銘柄は実現に時間がかかる可能性

## モデル設計（ノートブック原版）

### ラベル定義

| ラベル | 計算式 | 意味 |
|--------|--------|------|
| `label_high_20` | (基準日から20営業日後までの最高値 - 基準日終値) / 基準日終値 | 20日間の上昇余地 |
| `label_low_20` | (基準日から20営業日後までの最安値 - 基準日終値) / 基準日終値 | 20日間の下落リスク |

### 特徴量（原版：約190個）

**テクニカル系（60個）**

| グループ | 特徴量 | 窓幅 |
|---------|--------|------|
| リターン | `ror_N` | 1/5/10/20/40/60/100 |
| 出来高比 | `vol_N`, `d_vol` | 1/5/10/20/40/60/100 |
| ATR（前日終値ベース） | `range`, `atr_N`, `d_atr` | 1/5/10/20/40/60/100 |
| ギャップ | `gap_range`, `g_atr_N` | 1/5/10/20/40/60/100 |
| 日中変動 | `day_range`, `d_atr_N` | 1/5/10/20/40/60/100 |
| **ヒゲ幅** | `hig_range = ((高-安) - |終-始|) / 前日終値`, `h_atr_N` | 1/5/10/20/40/60/100 |
| ボラティリティ | `vola_N` | 5/10/20/40/60/100 |
| HL帯 | `hl_N` | 5/10/20/40/60/100 |
| **市場インパクト** | `mi = range / (出来高×終値)`, `mi_N` | 複数窓 |

**ファンダメンタルズ系（約130個）**

| グループ | 特徴量 | 内容 |
|---------|--------|------|
| フラグ | `annual`, `revision` | 本決算/四半期、訂正有無 |
| 実績 | `r_sales, r_ope_income, r_net_income` 等 | 実績損益 |
| 予想 | `f_sales, f_ope_income, f_net_income` 等 | 会社予想 |
| 収益性 | `r_pm1, r_roe1〜3, r_roa1〜3` 等 | 各種利益率 |
| 費用構造 | `r_cost1〜3, f_cost1〜3` 等 | 原価率・営業外費率等 |
| 効率性 | `r_turn, f_turn, equity_ratio` | 総資産回転率・自己資本比率 |
| 差分 | `d_*`（上記の前期差分） | 36個 |
| **マッチング（予想乖離）** | `m_sales = 実績売上 - 前期末予想売上` 等 | **決算サプライズ**の定量化 18個 |

### 訓練・評価設定

| 項目 | 値 |
|------|-----|
| 訓練期間 | 約3年（固定） |
| パージ期間 | **31営業日**（財務データの漏洩防止） |
| テスト期間 | 訓練後の全期間 |
| モデル | XGBRegressor × 2（high/low別） |
| 評価指標 | **Spearman順位相関係数** |
| リバランス | 日次 |

## 次ステップ・改善アイデア（優先順位付き）

### 優先度：高

1. **v2パラメータ復元実験**（depth=6, n=1000, tree_method="hist"）
   - v1と同条件でRを比較し、特徴量追加の純粋な効果を測定
   - 期待: R 0.24+ 達成できるか確認

2. **Long-Short バックテスト**
   - `pred_high_20`上位N銘柄ロング × 下位N銘柄ショート
   - Spearman相関 → 実リターンへの変換、Sharpe計算

3. **日中変動 × 決算サプライズの交差効果分析**
   - d_atr高 × m_sales正（好決算）の銘柄群で絞り込んだ場合のCAR
   - アイデア①「開示後の調整ラグ」の本丸

4. **TICKER カテゴリカル特徴量の追加実験**（2026-04-09 追加）

   **根拠**: JPXコンペ上位10モデルのうち5位・8位が独立に「銘柄コード(SecuritiesCode)をカテゴリカル特徴量にすると最重要特徴量になる」と報告。銘柄コードはセクター・時価総額・ボラ特性・流動性を暗黙的に集約するため、明示的特徴量では捕捉できない情報を補完する。
   - リファレンス: `docs/references/jpx-prediction/5th_lgbm_alpha_prediction.md`, `8th_lgbm_simple.md`

   **実装手順**:
   1. `FEAT_COLS` に `"ticker_cat"` を追加（L327付近）
   2. `train_evaluate()` 内（L354付近）で TICKER → 整数エンコード:
      ```python
      df["ticker_cat"] = pd.Categorical(df["TICKER"]).codes.astype("int32")
      ```
   3. XGBRegressor に `enable_categorical=True` を追加（L381）、かつ X を DataFrame で渡す（`.values` にすると型情報が消える）:
      ```python
      model = xgb.XGBRegressor(
          max_depth=5, learning_rate=0.05, n_estimators=500,
          colsample_bytree=0.5, subsample=0.5,
          tree_method="hist",
          enable_categorical=True,   # ← 追加
          n_jobs=-1, random_state=0, verbosity=0
      )
      # X_tr/X_te を DataFrame のまま渡す（.values 禁止）
      X_tr = train[available]        # ← .values を削除
      X_te = test[available]
      # ticker_cat 列の dtype を "category" に設定
      for d in [X_tr, X_te]:
          d["ticker_cat"] = d["ticker_cat"].astype("category")
      ```
   4. **比較実験**: ticker_cat あり/なしで Pearson R・方向正解率・分位別CARを比較

   **注意点**:
   - **過学習リスク**: 銘柄固有パターンは時間変化する。現行の単一時系列分割（TRAIN_END/TEST_START）だけでなく Walk-forward CV で検証推奨
   - **unseen ticker**: テスト期間に新規上場した銘柄は訓練時に存在しない → XGBoost の `enable_categorical` はunseen categoryを自動でハンドルするが、精度低下の可能性あり。フォールバック（unseen tickerは-1等のデフォルト値）を用意
   - **LightGBM 移行も検討**: XGBoost よりカテゴリカル特徴量のサポートが成熟。`categorical_feature` パラメータで指定するだけ。コンペ上位10中6がLightGBM

### 優先度：中

4. **追加データ探索**（データカタログ外も可）
   - 逆日歩・品貸料（日証金スクレイピング）→ 空売り圧力特徴量
   - 信用残高（J-Quants /margins）→ 需給特徴量
   - TDnet開示種別（BQ TDNET_*）→ 開示の種類でサプライズを分類

5. **予測期間の最適化**
   - MI高（低流動性）銘柄は保有期間を延長（20日→30日）
   - セクター別モデル分割

### 優先度：低

6. **マクロ条件付きモデル**
   - VIX/SKEW高期間 → テクニカル重視モデルへ切替
   - FREDから米金利・景気指標を特徴量として追加

## d_atr_5 上位20% ロングのみ バックテスト（2026-03-10）

### 投資アイデアとの紐づけ

**元アイデア**: 「d_atr（日中変動）が大きい銘柄は上昇余地が大きい（Spearman=0.170）」
→ d_atr_5 上位20%をロング保有することで超過リターンが得られるか検証

**アイデアステータス**: ANALYZED_PASS（統計的有意）→ **BACKTEST_FAIL**（インデックス劣後）

### バックテスト設定

- スクリプト: `scripts/backtest_datr_long.py`
- 手法: 日次PnLモデル（案C）。毎日 d_atr_5 上位20%を選定し20日ローリング保有
- 期間: 2023-06-02〜2025-12-29（テスト期間全期間）
- ユニバース: 1000銘柄（出来高上位）

### 結果

| 指標 | d_atr_5上位20% | TOPIX（1306.T） | 日経225（^N225） |
|------|---------------|----------------|-----------------|
| 総リターン | +16.2% | **+68.8%** | **+62.9%** |
| 年率リターン | +6.2% | **+23.3%** | **+21.5%** |
| Sharpe | 0.37 | **1.13** | **0.95** |
| MaxDD | −26.6% | −22.8% | −26.3% |
| 勝率（日次） | 54.0% | − | − |

### 判定: BACKTEST_FAIL

- TOPIX に対し年率 **−17.1%pt** の劣後
- 同期間（2023〜2025）は日本株全体が強烈な強気相場（円安・バフェット効果等）
- MaxDD は互角なのにリターンが 1/4 → リスクに見合わない

### 考察

- d_atr_5（日中変動が大きい）銘柄は**小型・低流動性バイアス**があり、大型株主導の強気相場でアンダーパフォーム
- Spearman 0.170（label_high_20）は「20日間の最高値」への相関。終値ベースの実リターンへの貢献は限定的
- **単独シグナルとしては使えない** → 次ステップは d_atr × MI（市場インパクト）交差分析（仮説③）
