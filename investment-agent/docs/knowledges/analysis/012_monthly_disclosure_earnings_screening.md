# IDEA: 月次開示→決算予測 ミスプライシングスクリーニング

## データソース
ユーザー手入力（2026-05-09）

## 根拠となった箇所
> 各四半期のPLに影響ある月次開示。例えば3月決算締めで4月末〜5月初旬に決算ある会社は、1月〜3月の月次開示の内容から業績予想が可能。月次開示では好決算が予想されるのに株価への織り込みが何故かされていないパターンにチャンスが潜んでいるという仮説。

本アイデアは既存パイプライン（042_monthly_disclosure_master.md）の「最終目標」と完全に一致。収集基盤は稼働済み（503社のextract adapter）だが、分析・スクリーニングは未着手。

## 投資アイディア
月次開示データ（売上・受注・既存店売上等）から四半期決算の業績を事前予測し、好決算が見込まれるが株価に未織り込みの銘柄を決算前に買う。

## 因果連鎖
1. 月次売上/受注の累積 → 四半期売上の大部分が事前に判明 → 決算発表でサプライズ → 株価上昇
2. 月次開示が好調 → 市場参加者が織り込み済み → 決算発表でサプライズなし → エッジなし（織り込み済みケース）
3. 月次開示が好調 → 市場参加者が無視/見落とし → 決算発表でサプライズ → 株価上昇（ミスプライシングケース）

## 時間軸（仮説）
- 月次開示: 翌月中旬〜下旬に前月分を開示（会社による）
- 決算との対応: 3月決算なら1-3月の月次→4月末〜5月の本決算
- エントリー: 四半期最終月の月次開示が出揃った時点（決算発表の2-4週間前）
- エグジット: 決算発表直後（翌営業日）
- 保有期間: 2-4週間

## 対象（粗い絞り込み）
- 月次開示を行っている上場企業（現在503社がadapter保有）
- 3月決算が多数だが、決算月は多様（2月・9月等の小売も多い）
- 小売・外食・不動産・建設（受注）等、月次KPIが売上と直結するセクター

## 分析の方向性（粗いイメージ）

### ロジック1: 月次開示→決算の相関分析
- 月次KPI（売上前年比、既存店売上比等）の四半期累積 vs 実際の四半期売上成長率の相関を過去データで測定
- 会社ごとに相関係数を算出し、「月次開示の予測力が高い会社」を特定
- メトリクスが非標準化（会社固有）のため、前年同月比ベースでの標準化が必要

### ロジック2: 織り込み度の定量化
- 月次開示から推定される決算サプライズ度 vs 月次開示期間中の株価リターンの関係
- 「月次が良いのに株価が上がっていない」= 未織り込み = チャンス
- コンセンサス予想（BQ: CONSENSUS）との乖離も織り込み度の代理変数

### Web調査: 投資家が月次開示で重視するポイント（2026-05-09）

**調査源**: 日経記事、株探、楽天証券トウシル、Nautical Star外食月次速報、学術論文検索

#### 投資家が重視する指標の優先順位

1. **既存店売上高（前年同月比）** — 最重視。新店効果を除いた純粋な成長力を示す
2. **全店売上高（前年同月比）** — 決算予測に直結。該当する決算期の月次の実績を平均することにより、四半期決算の売上高はかなり正確に予測できる（日経記事）
3. **客数（前年同月比）** — 売上の質を判断。客数増は持続的成長、客単価増のみは値上げ頼みでリスク
4. **客単価（前年同月比）** — 値上げ効果vs客離れの判断材料。「客単価を大きく低下させての客数達成、しかし売上前年未達」パターンが危険信号

#### 月次→決算予測の基本手法

- **月次累計→決算予測**: 毎月の月次を累計し、四半期決算の売上高を予測。会社予想と比較して上方修正期待を判断
- **全店売上の平均が決算予測に直結**: 月次全店売上YoYの3ヶ月平均≒四半期売上成長率
- 月次情報は「他の投資家も重視しており、ある程度はすぐに株価に織り込まれる」（日経記事の警告）

#### 織り込みに関する知見

- 月次開示直後に株価に一定程度反映されるが、**全ての投資家が月次を追跡しているわけではない**
- 特に**小型株・低流動性銘柄では織り込みが不完全**になりやすい（機関投資家のカバー外）
- 好業績でも「期待を下回る」とむしろ下落するため、**コンセンサス予想との乖離**が重要
- 決算前売却での利益確定も選択肢（織り込み済みリスク回避）

#### 外食業の開示パターン差異

- **全指標開示**（売上・客数・客単価）: マクドナルド、吉野家、鳥貴族等
- **売上のみ開示**: コメダ珈琲、やよい軒等
- **客数・客単価未開示**: サンマルク等
- 開示が詳細な会社ほど分析精度が高く、投資機会の発見確率も上がる

#### 見落としがちなポイント

- 客数増+客単価減（安売り集客）は売上維持でも利益率悪化 → **営業利益との相関が売上より弱くなる**
- 月次と決算の「期ズレ」: 月次は暦月、決算は事業年度ベースで1-2日のズレがある
- 神戸物産のように月次で売上・利益の両方を開示する会社は**営業利益予測精度が格段に高い**（少数）

### 予測力仮説のロジック（AI知見ベース、未検証）

**高予測力のメカニズム**: 月次KPI（特に既存店売上YoY）は四半期売上高の直接的な構成要素。3ヶ月分の月次売上を単純合算すれば四半期売上の大半が推計可能。

**低予測力のケース**:
- 受注高→売上高: 受注から売上計上までのラグが長い（建設業等）
- 台数→売上高: 単価変動・為替影響で台数≠売上（自動車等）
- ストック型: 月次売上変動が小さく、特殊要因（減損・M&A等）の影響が相対的に大きい

**営業利益の予測**: 売上高との相関が高い場合、営業利益率が安定している会社なら営業利益も予測可能。ただし原価変動が大きい業種（食料品・卸売業等）は売上→営業利益の変換が不安定。
