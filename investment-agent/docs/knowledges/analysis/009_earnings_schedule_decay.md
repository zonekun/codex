## 仮説

決算サプライズ発生 → PEAD（決算後ドリフト）開始 → 時間経過で情報織り込み進行 → シグナル強度が指数的に減衰 → 減衰を明示的にモデル化することでポジションサイズを最適化できる

従来のバイナリ方式（N日間ON→OFF）ではOFF境界でポジション不連続が発生し、ターンオーバーコストが増加する。連続的減衰関数を使うことで滑らかなポジション縮小が可能。

---

## 手法の概要

決算発表日からの経過営業日数 t に応じてシグナルウェイトを指数減衰させる:

```
signal_weight(t) = exp(-λ * t)
λ = ln(2) / half_life_days
```

- 決算日当日: weight ≈ 1.0
- 半減期経過後: weight ≈ 0.5
- 次の決算発表: リセット（weight = 1.0）

### 検証すべきパラメータ

- 半減期の最適値（10日? 20日? 40日?）
- 大型株 vs 小型株で半減期が異なるか
- 次の決算までの残日数による追加減衰の効果
- サプライズの大きさ × 減衰速度の相互作用

### 使用データ（想定）

| 項目 | 内容 |
|------|------|
| データソース | `STOCK.FIN_SUMMARY`（決算発表日）、`STOCK.STOCK_PRICE`（日次リターン） |
| 対象銘柄 | TOPIX500 or 全上場銘柄 |
| 粒度 | 日次 |
| 期間 | 要検討（5年以上推奨） |
