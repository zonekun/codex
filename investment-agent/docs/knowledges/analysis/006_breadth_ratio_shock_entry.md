## 投資アイデア

市場全銘柄のうち「5日間騰落率 ≤ -15%」の銘柄比率（BreadthRatio）が30%を超えたタイミングで高配当日本株を現物で仕込む。株価+20%リバウンドで売却するか、戻しが弱ければ実質6.25%超の配当利回りを享受する2段構えの戦略。

---

## 指標定義

### メインシグナル: BreadthRatio

```
BreadthRatio(t) = count(TICKER : ret5d(t) ≤ -0.15) / total_tickers

ret5d(t) = (Close(t) - Close(t-5)) / Close(t-5)
ユニバース: TOPIX構成銘柄 or STOCK_CODE_LIST全件
```

**通常時**: 0〜3%程度
**ショック時**: 20〜50%超に急上昇 → S/N 比が高く検出しやすい

### 補助シグナル: HighLowDrop5d（S/N比改善版）

```
HighLowDrop5d(t) = (max(High[t-4..t]) - Low[t]) / max(High[t-4..t]) × (-1)
```

単純終値比較（5日騰落率）よりパニック的売りが強調されるため、ノイズとシグナルの分離が向上する。

---

## 因果連鎖

```
市場ショック発生
  → 多数銘柄が5日で -15% 超下落
  → BreadthRatio 急上昇（30%超）
  → 売られ過ぎ状態の顕在化
  → 裁定・押し目買い流入 → 短期リバウンド
  → TOPIX / 高配当株でキャピタルゲイン取得
     または高利回り（6.25%超）で配当収取継続
```

---

## エントリー / エグジット条件

| 項目 | 内容 |
|------|------|
| エントリー | BreadthRatio > 30% に初めて到達した翌営業日の寄り付き |
| エグジット① | 株価 +20% リバウンド到達で確定売り |
| エグジット② | シグナル消滅（BreadthRatio < 閾値）から +5 営業日後 |
| 保有継続 | 戻しが弱ければ高配当を享受しながら保有継続 |
| クールダウン | エントリー後 20 営業日は再エントリーしない（独立性担保） |

### 閾値比較（動画バックテスト）

| 閾値 | 特性 | リーマン期 |
|------|------|-----------|
| 20% | 積極的・エントリー多 | 一時へこむ可能性 |
| **30%** | **保守的・推奨** | **初期へこみほぼなし** |

---

## 配当利回り付随効果

| 条件 | 効果 |
|------|------|
| 通常時配当利回り 5% の銘柄を -20% で仕込む | 実質利回り **6.25%** |
| +20% リバウンドで売却 | 短期キャピタルゲイン優先 |
| リバウンド小さければ保有継続 | 高利回り配当収取 |

## 分析の方向性

**CARイベント分析**が最適（イベント駆動型シグナルのため）

```
イベント定義 : BreadthRatio > 30% に初めて到達した日
エントリー   : イベント翌営業日（先取りなし）
CAR 計算窓  : +1, +5, +10, +20 営業日後の累積リターン
ベンチマーク : TOPIX 全期間平均リターン
多重比較補正 : BH 法（閾値を複数試す場合）
```

追加検証:
1. HighLowDrop5d を AND 条件に加えた場合の精度改善
2. 閾値 10%, 15%, 20%, 25%, 30% のスイープ比較
3. セクター別 CAR 比較（どのセクターがリバウンド強いか）

## ★ 使用アルゴリズム
