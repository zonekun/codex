## 概要

市販本「VWAPトレンド戦略」の手法を日本株市場（東証全銘柄）で検証。
週次・年次アンカードVWAP ±1σバンドへのタッチ後リターンを統計検定。

## ★ 使用アルゴリズム

### VWAP 計算（日足近似）

**典型価格**: `tp = (HIGH + LOW + CLOSE) / 3`

**アンカードVWAP**:
```
VWAP_t = Σ(tp_i × vol_i, アンカー日〜t) / Σ(vol_i, アンカー日〜t)
```

| アンカー種別 | アンカー日 |
|------------|---------|
| 週次 | 各週の月曜日（`DATE_TRUNC(YEARDATE, WEEK(MONDAY))`） |
| 年次 | 各年1月1日（`DATE_TRUNC(YEARDATE, YEAR)`） |

**出来高加重標準偏差**:
```
σ_t = √(E[tp²]_t - VWAP_t²)
E[tp²]_t = Σ(tp_i² × vol_i) / Σ(vol_i)
```

**選択理由**: 分足データは J-Quants Standard プランでは取得不可（Premium 必要）のため日足で近似。
VWAPの本来の意味（出来高加重平均価格）を日足レベルで再現する最善の近似。

### シグナル検出

**ロングシグナル（押し目買い）の条件**:
1. バンド傾斜 > +0.02%/5日（上昇トレンド判定）
2. 前日終値 > 前日上部バンド（バンド外に位置）
3. 当日安値 ≤ 当日上部バンド（バンドにタッチ）
4. 当日終値 > 上部バンド × 0.97（バンド付近以上で引け）

**ショートシグナル（戻り売り）の条件**:
1. バンド傾斜 < -0.02%/5日（下降トレンド判定）
2. 前日終値 < 前日下部バンド（バンド外に位置）
3. 当日高値 ≥ 当日下部バンド（バンドにタッチ）
4. 当日終値 < 下部バンド × 1.03（バンド付近以下で引け）

**エントリー**: タッチ日の終値でエントリー（翌日寄付きではなく当日終値）

### 統計検定

t検定（1標本、帰無仮説: μ=0）を各ホライズン・シグナル種別で実施。
**選択理由**: サンプルサイズが70万〜140万件と大きく中心極限定理が十分適用される。Mann-Whitney U も
代替として有効だが、t検定で十分。

## 判定と理由

**ANALYZED_PASS**

- **LONGは3日後以降で有意にプラスリターン**（t=+18〜+49, p<0.001）
- **SHORTも5/10日後で統計有意**（ショート方向に株価が動く傾向）
- サンプルが70〜140万件と十分大きく、統計的信頼性は高い
- 平均リターンの絶対値は小さい（0.1〜0.4%）が、高頻度・多銘柄で積み上げ可能

---

## 注意事項・制約

- **日足VWAP近似**: 本来の分足VWAPより精度が落ちる。分足（Premium プラン）で再検証すると結果が変わる可能性
- **エントリー価格**: 当日終値でのエントリーは実際には不可（翌日寄付き想定が現実的）
- **取引コスト未考慮**: 手数料・スリッページを考慮すると有意差が消える可能性あり
- **シグナル過多**: 1日に全市場で数千シグナルが発生する。ポートフォリオ制約・フィルタリングが必要
- **勝率が低い**: 最大50.1%。高頻度で薄利を積み上げる戦略

## バックテスト結果（2026-03-07）

**BACKTEST_FAIL**（`scripts/vwap_backtest.py`）

| SHORT | 21,196 | -0.442% | 51.0% | -0.193 |

**バックテスト設定**: 週次アンカー、HOLD_DAYS=10、往復コスト0.2%、出来高フィルタ10万株、同時保有上限20銘柄

### 失敗原因: オーバーナイトギャップ

統計分析では+0.40%（シグナル日終値エントリー）だったが、翌日寄付きエントリーでは-0.24%（コスト前）。
差分約-0.64% = **バンドタッチ翌日の窓開け下落（ギャップダウン）**が全リターンを食い潰している。

### 改善案（未実施）

1. 当日終値エントリーへ変更（より厳密な検証）
2. ギャップフィルタ：翌日始値 > 前日終値の場合のみエントリー
3. 流動性最上位銘柄（ETF含む）に絞る
4. 損切りライン（-1%等）の追加
5. 分足データ（Premium プラン）での精度向上
