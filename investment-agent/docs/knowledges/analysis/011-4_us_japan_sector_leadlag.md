## なぜ 011-1/2/3 が全滅した後にこれを試すのか

011-1/2/3 の失敗はすべて**「個人投資家が前日夜に注文する必要があるため、シグナルを1日ずらさなければならない」**ことが原因だった。日本市場内の情報拡散は日足レベルでほぼ即座に完了するため、1日ずらすとシグナルが消滅した。

**米国→日本は構造が根本的に異なる**:
- 米国市場の引け = JST 6:00 頃（冬時間）/ 5:00 頃（夏時間）
- 日本市場の寄付 = JST 9:00
- **3〜4時間の余裕**がある
- 個人投資家は朝6:00〜8:59にシグナル計算+寄成注文が可能
- **オプションAの執行が論文のターゲット（翌日Open-to-Close）と完全に一致**
- **1日ラグ問題が原理的に発生しない**

これは「米国を使わない応用」ではなく、「**論文どおりの構造が個人投資家に最適だった**」という結論。011-1/2/3 の失敗を経て初めてたどり着いた回帰。

## 仮説（論文そのまま）

米国市場で時点 t に確定した業種別情報は、日本市場の翌営業日 t+1 の日中リターン（Open→Close）に波及する。

因果連鎖:
```
米国セクターETF close-to-close（日 t） → 共通ファクター抽出（低ランクPCA）
  → 日本セクターETF の翌営業日 open-to-close（日 t+1）を予測
    → 上位セクターをロング
```

## シグナル構造（論文式 (13)〜(21) そのまま）

### V₀ (K₀=3)

論文と同一:
1. **v₁**: 全28要素等ウェイト（グローバルファクター）
2. **v₂**: 米国=+1, 日本=-1（国スプレッド）→ v₁に直交化
3. **v₃**: シクリカル=+1, ディフェンシブ=-1 → v₁,v₂に直交化
   - 米国シクリカル: XLB, XLE, XLF, XLRE
   - 米国ディフェンシブ: XLK, XLP, XLU, XLV
   - 日本シクリカル: 1618, 1625, 1629, 1631
   - 日本ディフェンシブ: 1617, 1621, 1627, 1630

### V₀ と実際の伝播経路の関係（重要な注記）

V₀ の v₃ は「シクリカル vs ディフェンシブ」という**粗い1方向のヒント**に過ぎない。実際の米日セクター間の伝播は**もっとセクター固有**である。例えば:
- 米国 Financials (XLF) が上がった → 翌日 日本の銀行 (1631) が上がる
- 米国 IT (XLK) が上がった → 翌日 日本の電機・精密 (1625) が上がる
- 米国 Energy (XLE) が上がった → 翌日 日本のエネルギー資源 (1618) や商社 (1629) が上がる

※ 上記は説明のための例示であり、実際のETF/セクター定義と1対1で対応しない組合せも含む（例: FANG→半導体、のような業種横断の伝播も存在しうる）

**これらの個別セクター間の対応関係は V₀ で手動設計するものではなく、B_t = V_JP V_USᵀ の 17×11 行列の中身が正則化PCA の固有分解で自動的に学習する**。V₀ はその学習を安定させるための「初期方向のヒント」（Ledoit-Wolf 縮約の事前情報）であり、伝播の全貌を記述するものではない。

### K=3 は「パラメータ」ではなく「設計要件」（Pass 2 で確認済み）

Pass 2 の感度分析で K=2→K=3 に Sharpe の崖（0.16→1.62）が見つかった。これは**パラメータの脆弱性ではなく、モデル設計の構造的要件**。

3本の事前固有ベクトルはそれぞれ独立した経済的役割を持つ:

| K | 含まれるベクトル | 何が分かるか | Sharpe |
|---|---|---|---:|
| 1 | v₁（グローバル）のみ | 世界全体のリスクオン/オフ。**どのセクターかの情報ゼロ** | -0.69 |
| 2 | + v₂（国スプレッド） | 米日のどちらが強いか。**セクター内の強弱は不明** | 0.16 |
| **3** | **+ v₃（シクリカル/ディフェンシブ）** | **セクター間の対応関係が入る。ここで初めて予測が機能** | **1.62** |
| 5 | + データドリブン2本 | ノイズ混じりの追加方向。足しても害にならないが改善もわずか | 1.67 |

v₃ を入れて初めて「米国の景気敏感セクターが動いたら日本の景気敏感セクターも動く」という**セクター間の対応関係**がモデルに入る。v₃ なしでは対応関係がないので予測できない。

**したがって K=3 は固定要件**。チューニング対象ではない。K≥3 であれば安定（K=5 で +0.05 のみ）。K<3 は部品が足りない不完全モデル。

### 正則化PCA

- L=60 営業日ローリング窓
- 結合相関行列 C_t (28×28): 米国 c2c + 日本 oc をラグペアで結合
- C_t^reg = 0.1 · C_t + 0.9 · C₀
- C₀: 長期ウィンドウ（warm-up 期間全体）から推定
- 上位 K=3 固有ベクトル → V_US (11×3), V_JP (17×3)

### 予測器

```
B_t = V_JP,t @ V_US,t.T  ∈ ℝ^(17×11), rank ≤ 3
ẑ_JP,t+1 = B_t @ z_US,t
```

z_US,t = 米国セクターの当日標準化 c2c リターン（ウィンドウ内の平均・標準偏差で標準化）

- **ロングショート**: シグナル上位 q をロング、下位 q をショート（市場中立）

- **リバランス**: **日次** or **週次**（ETFは17本しかないので日次でも管理可能）
- **コスト**: ETFは大型で流動性高い → 片道 1-2 bps
- **税金**: 20.315%

## 検証履歴

### Pass 1a（ロングオンリー、2023-2024 OOS）

- グロス Sharpe 0.856（top-3 日次）、税後 Sharpe 0.385 → **FAIL**
- ショートサイドの収益が取れないことが主因

### Pass 1b（ロングショート、2023-2024 OOS）

- グロス Sharpe **1.668**、コスト後 **1.236**、税後 **0.985** → 基準 1.0 にあと 0.015
- ほぼ合格。期間拡大で確認する価値あり → Pass 2 へ

### Pass 2（期間拡大 2018-2024 OOS、パラメータ感度分析）

- 全期間税後 Sharpe **1.623** → **条件1 PASS**
- 年次安定性 7/7 年でグロス Sharpe > 0 → **条件2 PASS**
- パラメータ頑健性: λ/L は頑健。K=2→3 で崖あり（ただし構造的要件、脆弱性ではない） → **条件3 条件付き PASS**
- K=3 は「グローバル + 国スプレッド + シクリカル/ディフェンシブ」の3因子を全て入れる設計要件。K≥3 では安定（K=5 で Sharpe 1.67）
- 単ファクター α: 32.26%/yr, NW t=6.52（高度に有意）

### 深掘り（2023-2026-Q1、月次/四半期/Rolling IC）

- **2024年の減衰は一時的** → 2025年に税後 Sharpe **1.06** で回復を確認
- **2026-Q1 の急落**（Sharpe -2.50, MDD -15.3%）はイラン戦争による地政学ショックで市場全体のレジームが崩壊したことが原因。戦略の構造的欠陥ではない
- **Rolling IC**: 2025年は平均 +0.038 で安定回復。2026-Q1 で -0.016 に転落（地政学ショックと一致）
- Kill Switch 閾値候補: 12週 Rolling IC < -0.02 でポジション縮小

### 最終判定

**ANALYZED_PASS（条件付き）**。条件:
1. **Rolling IC Kill Switch を組み込むこと**（地政学ショック等のレジーム崩壊期に自動停止）
2. **K=3 を固定要件として変更しないこと**（シクリカル/ディフェンシブ因子は必須）
3. 次のフェーズ: バックテスト設計（Kill Switch パラメータ確定 + 執行シミュレーション + 日次オペレーション手順書）
