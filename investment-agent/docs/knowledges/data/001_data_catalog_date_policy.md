# data_catalog.md における日付・件数の記載方針

**カテゴリ**: data
**作成日**: 2026-02-23
**ステータス**: 有効
**関連ファイル**: `data_catalog.md`

## 概要

`data_catalog.md` に記載するデータ件数・期間（TO）は時間とともに変化するため、
スナップショット値を固定記載せず「確認履歴テーブル」形式で管理する。

## 詳細

### 方針

| 項目 | NG（固定記載） | OK（推奨） |
|------|--------------|-----------|
| 期間（TO） | `期間: 1998-01-02 〜 2026-02-20` | `TO は更新のたびに変わる。実際の値はファイル/クエリで確認` |
| 総行数 | `総行数: 7,042件` | 確認履歴テーブルに追記 |
| 最新日付 | `最新日付: 2026-02-20` | 確認履歴テーブルに追記 |

### 確認履歴テーブル形式

更新・確認のたびに1行追記する。削除・上書きしない。

```markdown
**確認履歴（確認のたびに追記）:**
| 確認日 | 総行数 | 最新日付 |
|--------|--------|---------|
| 2026-02-22 | 約 24,110,124件 | 2026-02-20 |
```

### 期間（FROM）の扱い

- **固定の場合**（例: bond_history.csv の 1998-01-02）: そのまま記載してよい
- **可変の場合**（例: STOCK_PRICE の「2010年以降」）: 「2010年以降（固定）」と明記

### 実際の最新値の確認方法を明記する

BQ テーブルは SQL クエリ、CSV はファイル読み込みで最新値を取得できるよう、
確認方法をカタログに記載する。

例（BQ）:
```sql
SELECT MAX(YEARDATE) FROM `gmailpj-357912.STOCK.STOCK_PRICE`
```

例（CSV）:
```python
import pandas as pd
df = pd.read_csv("data/csv/bond_history.csv")
print(df["DATE"].max())
```

### 適用済みデータ（2026-02-23 時点）

| データ | 適用日 |
|--------|--------|
| `STOCK.STOCK_PRICE` (BQ) | 2026-02-23 |
| `STOCK.STOCK_CODE_LIST` (BQ) | 2026-02-23 |
| `data/csv/bond_history.csv` | 2026-02-23 |

## 根拠・出典

- `bond_history.csv` の TO 日付がセッション間で陳腐化することを確認したため方針を策定
- 新規データをカタログ登録する際も同方針を適用すること
