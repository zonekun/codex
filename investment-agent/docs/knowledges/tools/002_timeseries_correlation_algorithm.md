## なぜスピアマン相関は不適切だったか

### 問題: 自己相関による見せかけの相関

| 系列 | ACF(lag1) | ACF(lag2) | 性質 |
|------|----------|----------|------|
| 野菜平年比（水準） | **0.96** | **0.90** | 非常に強い持続性（ゆっくり変動）|
| 株式週次リターン | ≈ 0 〜 0.05 | ≈ 0 | ほぼホワイトノイズ |

野菜が高い期間（例: 冬場10週連続）にたまたまスーパー株も強かっただけで、
ランク順序の類似性としてスピアマン相関が出てしまう（見せかけの相関）。

### ADF検定の結果（2017〜2026, 379週）

| 系列 | ADF統計量 | p値 | 判定 |
|------|---------|-----|------|
| 平年比（水準） | -3.480 | 0.0085 | 技術的には I(0) だが ACF≈0.96 で強い持続性 |
| 平年比（1階差分） | -7.065 | <0.0001 | 明確に I(0) |
| 株式週次リターン | — | <0.01 | I(0)（理論・実証ともに自明）|

→ 平年比の水準は「ぎりぎり定常」だが自己相関が極めて強く、
　スピアマン・ピアソンをそのまま適用すると偽の相関が生じる。

## 採用するアルゴリズム

### フロー

```
[Step 1] 前処理（定常化）
         平年比 → 1階差分: Δh_t = h_t - h_{t-1}
         株式リターン: r_t  (変換不要、既に定常)

[Step 2] 事前白色化（Prewhitening）
         Δh_t に AR(p) を当てはめ → 残差 ε_t
         r_t  に AR(p) を当てはめ → 残差 η_t
         ※ 各系列に残った自己相関を除去する

[Step 3] 事前白色化後 CCF（相互相関関数）
         CCF(ε_t, η_{t+k}) を k = -4 〜 +4 週で計算
         → どのラグで cross-correlation が有意か確認
         → 95%信頼区間: ±1.96/√n

[Step 4] グレンジャー因果性検定（VAR フレームワーク）
         VAR(p) を [Δh_t, r_t] に当てはめ
         H0: 「Δh_{t-1},...,Δh_{t-p} は r_t を予測しない」
         を F 検定（または χ² 検定）で棄却できるか確認
         → 野菜価格変化 → 株価リターンの方向性のある予測関係を検定

[Step 5] イベント分析（CAR ベース）
         Δh_t の急騰イベント定義（例: Δh_t > 95th percentile）
         イベント前後の株式累積超過リターン（CAR）を計算
         CAR = Σ(r_{t+k}) for k=0,1,2,4 weeks
         分布の比較: Mann-Whitney U（ただし白色化後の系列で実施）
```

### 各手法の役割

| 手法 | 目的 | 何を答えるか |
|------|------|------------|
| ADF検定 | 前提確認 | 各系列が定常か？ |
| 事前白色化 CCF | 探索 | どのラグで相関があるか？ |
| グレンジャー因果性 | 推論 | 野菜価格変化が株価を（統計的に）予測するか？ |
| CAR イベント分析 | 実務 | 急騰後の超過リターンは有意に負か？ |

### グレンジャー因果性を採用する理由

- スピアマン/ピアソンは「相関があるか」しか答えない
- グレンジャーは**「A の過去が B の未来を予測するか」**（方向性付き）
- 投資判断に必要なのは「野菜価格変化で来週の株価を予測できるか」→ グレンジャーが直接これに答える
- VAR に含めることで各系列の自己相関を自動制御できる

## 実装上の注意

### ラグ次数の決定
- VARのラグ次数はAIC/BICで自動選択
- 週次データで通常 p=1〜4（1ヶ月以内）が経済的に自然

### サンプルサイズ
- 379週（2017〜2026）は最低限。グレンジャーはラグp=4なら自由度はOK
- 銘柄ごとに欠損週がある場合は有効観測数が減る点に注意

### 多重比較補正
- 15社 × 複数ラグでテストすると偽陽性が増える
- Bonferroni 補正またはFDR（Benjamini-Hochberg）を適用

### 実際に意味のある結果の解釈
- 「統計的有意 ≠ 投資で使える」
- Granger因果で p<0.05 でも偏回帰係数が小さければ予測力は低い
- 偏回帰係数（β）のサイズと符号も必ず確認する

## statsmodels AutoReg 実装上の注意

```python
from statsmodels.tsa.ar_model import AutoReg

# ✅ 正しい初期化
fit = AutoReg(series, lags=p, old_names=False).fit()
#                              ↑ 必須。省略すると DeprecationWarning が出る

# ラグリストの取得
lags_list = fit.model.ar_lags   # → [1, 2, ..., p] のリスト
p_max     = max(lags_list)

# ❌ 誤り（AttributeError になる）
# p = fit.model.lags   → 存在しない属性名
```

- `old_names=False` を省略すると係数名が旧形式で返り警告が出る
- ラグ次数の取得は `fit.model.ar_lags`（リスト形式）
  - AIC最小のラグが選ばれる。例: p=3 なら `[1, 2, 3]`
- `fit.resid` で学習期間の残差が取れるが、先頭 p 行は欠損（AR のバーンイン）
