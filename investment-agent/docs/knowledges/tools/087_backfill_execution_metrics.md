# 087: TDnet バックフィル 実行メトリクス

> フェーズ別の実測所要時間・レコード件数を記録。後続バッチの所要時間見積もり・リソース計画に使う。

## パイプライン構成（4フェーズ）

```
tdnet-load-daily → [ai-prepare × N四半期（並列）] → [Gemma TPU × N（並列）] → [ai-finalize × N（並列）]
```

- **load**: TDnet PDF を GCS + BQ (DOCUMENTS_ENHANCED) にロード
- **ai-prepare**: OCR + regex 抽出。Cloud Run Job
- **Gemma TPU**: Spot TPU v6e-4 で AI 推論。`_SUCCESS` マーカーで完了通知
- **ai-finalize**: Embedding 生成 + BQ INSERT。Cloud Run Job
