# J-LENS（AI開示情報検索サービス）

**カテゴリ**: tools
**作成日**: 2026-03-23
**ステータス**: 有効（β版）
**関連ファイル**: `docs/knowledges/tools/003_tdnet_download.md`, `docs/knowledges/tools/013_tdnet_load.md`

## 概要

JPX（日本取引所グループ）が提供するAIを活用した開示情報検索サービス。
TDnet（適時開示情報閲覧サービス）の開示書類をAI検索できる。β版として提供中（2025年12月〜）。

## サービス情報

| 項目 | 内容 |
|------|------|
| サービスURL | https://www.tse-g.com/ |
| 概要リリース | https://www.jpx.co.jp/corporate/news/news-releases/6020/20251209-01.html |
| 提供元 | 東京証券取引所（JPX） |
| ステータス | β版（無償提供期間中） |

## 機能

- TDnet に掲載された上場企業の適時開示書類を**自然言語で検索**
- AIが書類内容を解析し、関連度の高い開示を返す
- 対象: 有価証券報告書・決算短信・月次開示・適時開示全般

## 本プロジェクトとの関係

本プロジェクトでは TDnet 開示書類を GCS + BigQuery にダウンロード済みのため、
**基本的にはローカルデータで完結する**。ただし以下の場面で補助的に活用できる可能性がある：

### 活用が想定される場面

| 場面 | 活用例 |
|------|--------|
| **特定開示の存在確認** | ある銘柄がある期間に月次開示を出しているか素早く確認 |
| **開示内容の文脈確認** | BQ/GCSにあるPDFの内容を自然言語で概要把握 |
| **新規銘柄のアダプター設計** | 月次開示パイプラインの adapter.json 作成時に、対象銘柄の開示パターンを調査 |
| **投資アイデアの開示根拠探索** | 「○○に関する開示を出している企業」を横断検索 |
| **GCS未取得期間の補完確認** | ダウンロード漏れがある期間の開示があるか確認 |

### 使わなくて良い場面

- BQ `TDNET_DOCUMENTS_ENHANCED` または GCS `tdnet/` に既にある書類の内容確認
- 定量分析・バックテストのデータソース（構造化データが必要なため）

## 注意事項

- β版のため、仕様変更・サービス終了の可能性あり
- 検索結果はAIによる解析のため、完全性は保証されない
- 本格的なデータ取得・分析には GCS/BQ の既存パイプラインを使うこと
