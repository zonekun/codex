# 株主優待 構造化加工プロンプト v2

**用途**: 中間JSONL → 加工済みJSONL への変換指示。Claude Code直接 / Codex委任 両方で使用。
**親知見**: `docs/knowledges/tools/098_yutai_scraper.md`
**旧版**: `docs/knowledges/tools/098_yutai_format_prompt_v1.md`

## 入力

中間JSONL。各行:
```json
{"ticker": "9936", "name": "王将フード", "kenri_kakutei": "3月末、9月末", "yutai_text": "≪優待内容≫\n..."}
```

## 出力

加工済みJSONL。各行に `yutai_content`（整形済み優待内容テキスト）を追加:
```json
{"ticker": "9936", "name": "王将フード", "kenri_kakutei": "3月末、9月末", "yutai_content": "株主優待券(500円券) 必要株数：100 100:2,000円分 ..."}
```

## 加工手順（2段階抽出）

### Pass 1: 優待品名・ティア構造の抽出

`yutai_text` を読み、以下を抽出:

- 優待品の品名・金額・数量
- 株数ティア別の内容（`100:XXX 500:YYY` 形式）
- 随時優待（「随時」プレフィックス付き）
- 複数選択肢は `(1)Xまたは(2)Y`
- ティア内の選択は「または」、複合は「および」
- 異なる優待種別は4スペース区切りで独立セクション
- 見学会・抽選等は独立セクション

**Pass 1では保有条件の記載は不要。** ティア構造に保有期間が組み込まれている場合（例: `1年以上:1,000円、3年以上:3,000円`）はそのまま含める。

### Pass 2: 継続保有条件の抽出

`yutai_text` を読み、以下を抽出:

- 継続保有条件（必要な保有期間）
- 長期保有による増額情報

**簡潔化ルール**: 判定方法の詳細（株主名簿・連続記載回数・基準日列挙）は除去し、保有期間の要約のみ残す。

| 生データ | 出力 |
|---------|------|
| 同一株主番号にて2回連続(11月末及び5月末)で株主名簿に記載または記録されている株主 | 6カ月以上継続保有の株主のみに贈呈 |
| 株主名簿基準日に連続3回以上1単元以上記載された同一株主番号の株主 | 1年以上継続保有が必要 |
| 同一株主番号で初めて登録されてから5年以上 | 5年以上継続保有 |

**例外（残す）**: 途中で株数を下回った場合の失効条件、ポイント繰越条件等、保有期間以外の特殊条件。

### マージ

1. Pass 1 の出力を基本構造とする
2. Pass 2 の保有条件を末尾に `※` 注記として付加（簡潔表現で）
3. 長期保有増額: ベース金額＋増額注記形式を優先（後述の表現ルール参照）

## フォーマットルール

### 出力形式

- 1レコード = 1行テキスト
- セクション区切り: 4スペース
- ティア: `必要株数：N N1:内容1 N2:内容2`
- 継続保有条件: セクション末尾に `※` で付記（簡潔に）
- 利用条件・補足（残留判定を通過したもの）: `※` で付記、複数は `◆` 区切り
- 随時優待: 「随時」プレフィックス
- `?` マーク: 文脈から推定して置換、推定不能なら除去

### 長期保有増額の表現ルール

保有期間×株数の二次元ティアは、ベース＋増額注記で表現する:

**悪い例**（読みづらい）:
```
100:1年以上1,000円相当/3年以上1,000円相当 600:1年以上1,500円相当/3年以上2,000円相当 1000:1年以上2,000円相当/3年以上5,000円相当
```

**良い例**（ベース＋増額注記）:
```
必要株数：100 100:1,000円相当 600:1,500円相当 1000:2,000円相当 ※1年以上継続保有の株主のみに贈呈。3年以上継続保有の場合、600株以上1,000株未満は500円増、1,000株以上は3,000円増
```

### 除去対象

以下はノイズとして除去する:

**権利確定月・期間情報**:
- 贈呈時期（`贈呈時期：...`、`≪贈呈時期≫`）
- 権利確定月・基準日の記述（`※年N回(X月・Y月)` 等）
- 角括弧の期区分表記（`[期末優待(5月末基準)]`、`[中間優待(11月末基準)]`）

**ページUI・免責**:
- 免責文言（`●株主優待情報を...`）
- ランキング・メニュー等のページUI要素
- `アクセスランキング` 以降のテキスト全体
- `●株主優待情報を投資の判断材料` 以降の免責テキスト
- 送付先情報（`≪送付先≫`）
- 日付表記（`（2026年4月21日現在）`）
- 写真キャプション（`［写真1］※写真は...`）
- 適用時期セクション（`【適用時期】...`、`【適用実施日】...`）

**自明な利用条件**（投資判断に影響しない情報）:
- 利用方法の制約: 「1注文で複数枚利用可」「1度きりでの利用」「お釣りは出ない」
- 必要アカウント: 「Yahoo! JAPAN IDが必要」「優待専用WEBサイトで利用」
- 利用不可商品: 「一部対象外商品あり」「処方箋薬やタバコ等には利用不可」
- 利用金額条件: 「券面額以上(税込)の買い上げ時に利用可」「注文合計N円未満は配送料あり」
- 有効期限: 「有効期限は発効日から1年間」「利用期間は〜まで」
- 変動可能性: 「天候により別の優待品になる場合あり」
- 自明な資格: 「新規・既存問わず」
- 貸株注意書き: 「貸株サービス利用の場合、株主優待や長期保有条件の対象外となる場合あり」

**判定の一般原則**: 「その条件を知らなくても、優待の価値判断（何がいくら分もらえるか）に影響しない」なら除去。

### 残留判定（除去してはいけないもの）

以下は優待内容の実質的な拡張・制限であり、残す:

- **代替選択肢**: 「対象店舗のない地域の株主は代替として〜を選択可」
- **特殊条件**: ポイント繰越条件、失効条件（途中で株数を下回った場合等）
- **将来の制度変更**: 「2027年5月以降、長期保有特典新設」等
- **利用上限**: 「1泊につき1,000円上限で宿泊料金に利用可」（金額に直結）

**判定の一般原則**: 「その情報があることで、優待の実質的な金銭価値や選択肢が変わる」なら残す。

### 複数権利確定月の処理

- 月ごとに優待内容が異なる場合: 各月の内容を切り出して個別の `yutai_content` を生成
- 全月共通の場合: 同じ `yutai_content` を使用（シート振り分けは Excel 生成スクリプトが行う）
- `～変更前～` / `～変更後～` がある場合: 現在適用される方を使用

## Few-shot Examples

### Example 1: 自明条件除去（2678 アスクル）

**入力**:
```
kenri_kakutei: 5月20日、11月20日
yutai_text: ...LOHACO 2,000円分割引クーポン（500円×4枚）...501円（税込）以上の商品1点につき500円利用可...1注文で複数枚利用可...Yahoo! JAPAN IDが必要...一部対象外商品あり...注文合計3,780円(税込)未満は配送料あり...
```

**出力**:
```
yutai_content: LOHACO 2,000円分割引クーポン(500円×4枚) 必要株数：100 ※501円(税込)以上の商品1点につき1枚(500円)利用可
```

→ 利用方法制約・必要アカウント・対象外商品・配送料は除去。最低利用金額は「1枚あたりの実質価値」に直結するため残留。

### Example 2: 利用制限除去＋代替選択肢残留（3148 クリエイトＳＤ）

**入力**:
```
kenri_kakutei: 5月末
yutai_text: ...「薬クリエイト」買物優待券(1枚500円相当)...100株以上:3枚(1,500円分)...クリエイトエス・ディーの店舗で券面額以上(税込)の買い上げ時に利用可。調剤薬局では利用不可...処方箋薬やタバコ等一部商品には利用不可...有効期限は発効日から1年間...対象店舗のない地域の株主は代替選択可...
```

**出力**:
```
yutai_content: 「薬クリエイト」買物優待券(1枚500円相当) 必要株数：100 100:3枚(1,500円分) 300:8枚(4,000円分) 1500:16枚(8,000円分) 3000:24枚(12,000円分)◆※対象店舗のない地域の株主は代替選択可: 100株以上300株未満は全国共通お米券3枚(1,320円分)、300株以上は当社指定のカタログギフト
```

→ 利用可能店舗・利用不可商品・有効期限は除去。代替選択肢は実質的な優待内容のため残留。

### Example 3: 継続保有条件の簡潔化（4577 ダイブ）

**入力**:
```
kenri_kakutei: 5月末、11月末
yutai_text: ...デジタルギフト...100:500円相当 600:1,000円相当 1000:1,500円相当...半年以上継続保有が必要（同一株主番号にて2回連続(11月末及び5月末)で株主名簿に記載または記録されている株主）
```

**出力**:
```
yutai_content: デジタルギフト(Amazonギフトカード/PayPay/楽天ポイント他から選択) 必要株数：100 100:500円相当 600:1,000円相当 1000:1,500円相当◆※6カ月以上継続保有の株主のみに贈呈
```

→ 判定方法の詳細（株主番号・連続記載回数・基準日列挙）は除去し、保有期間の要約のみ。

### Example 4: 保有期間ティアをベース＋増額注記に（3645 メディカルネット）

**入力**:
```
kenri_kakutei: 5月末
yutai_text: ...デジタルギフト...1年以上: 100株1,000円/600株1,500円/1000株2,000円...3年以上: 100株1,000円/600株2,000円/1000株5,000円...1年以上の判定は連続3回以上...3年以上は連続7回以上...
```

**出力**:
```
yutai_content: デジタルギフト(Amazonギフトカード/PayPay/楽天ポイント/dポイント/auPAY/nanacoポイント他から選択) 必要株数：100 100:1,000円相当 600:1,500円相当 1000:2,000円相当 ※1年以上継続保有の株主のみに贈呈。3年以上継続保有の場合、600株以上1,000株未満は500円増、1,000株以上は3,000円増
```

→ ベース（1年以上）を主表記、3年以上は差分（増額）で注記。判定方法詳細は除去。

### Example 5: 権利確定月表記の除去（4465 ニイタカ）

**入力**:
```
kenri_kakutei: 5月末、11月末
yutai_text: [期末優待(5月末基準)] (1)ジェフグルメカードまたは(2)日本旅行ギフト旅行券...100:ジェフグルメカード(500円相当)...
```

**出力**:
```
yutai_content: (1)ジェフグルメカードまたは(2)日本旅行ギフト旅行券 必要株数：100 100:ジェフグルメカード(500円相当) ...
```

→ `[期末優待(5月末基準)]` は権利確定月の記述として除去。

## Codex委任時の追加指示

- **日本語エンコーディング**: スクリプト実行時は `PYTHONUTF8=1` を付ける。ファイル open は全て `encoding="utf-8"` を明示する。openpyxl の .xlsx は内部UTF-8なので Excel 自体のエンコーディング指定は不要だが、**中間JSONL の読み書きで encoding 指定を省略すると文字化けする**
- 入力JSONLパスと出力JSONLパスを引数で受け取る
- 1レコードずつ処理し、逐次出力JSONLに追記する
- 処理完了時、伝言板に完了報告＋出力JSONLパスを記載
- 必要ライブラリ: なし（標準ライブラリのみ）
- Excel生成は `scripts/generate_yutai_excel.py` を別途実行
