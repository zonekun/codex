# TDnet 適時開示 カテゴリ分類ロジック

**カテゴリ**: tools
**作成日**: 2026-02-25
**ステータス**: 有効
**関連ファイル**: `scripts/tdnet_download.py`
**関連プラン**: `docs/plans/tools-006_tdnet_category_classification_20260430_210000.md` — カテゴリ定義の一元化・乖離解消

## 概要

TDnet の適時開示タイトルを正規表現でカテゴリ分類し、投資判断への重要度（S/A/B/C）を付与する。
C と一部の B はダウンロードをスキップする。

---

## ⚠️ 重要な注意: このファイルの目的は「取り込み対象の選別」だけ

**このカテゴリ分類と S/A/B/C の優先度は、TDnet 開示書類を BQ/GCS に取り込むか否かを決めるためだけに存在する**。以下は**絶対に誤解しないこと**:

- **S/A は「株価に影響が大きい」ことを意味しない**。あくまで「取り込んでおきたい重要資料」の印であり、統計的な裏付けは持たない
- **B/C は「株価に影響が小さい」ことを意味しない**。あくまで「保存コスト対効果が低いのでスキップ」の印
- 「理由」欄の記述（例: "翌日の株価に直撃"、"需給改善シグナル"）は**分類当時の経験則的な直感**であり、実データで検証された市場インパクトではない
- このファイルの優先度を**戦略シグナルや特徴量の重み付けに流用するのは禁止**。実際の市場影響度を測りたい場合は必ず CAR イベント分析等で別途検証すること

この注意書きは、過去に「S/A カテゴリの密度 → 翌日リターン予測」のような応用アイデアが検討された際、本ファイルの優先度を統計的裏付けがあるものと誤解しないために追加された。投資戦略で TDnet カテゴリを使う場合は、**カテゴリ名の分類結果のみを利用し、S/A/B/C の重要度ラベルは無視すること**。

## 優先度の定義

| 優先度 | 意味 | DL |
|--------|------|-----|
| **S** | 最重要。株価に即時かつ大幅な影響 | ✅ |
| **A** | 重要。需給・業績・構造変化に影響 | ✅ |
| **B（要）** | 参考。状況次第でインパクトあり | ✅ |
| **B（不要）** | 参考だが投資判断への直接影響薄い | ❌ |
| **C** | 不要。個別株投資と無関係または定型開示 | ❌ |

## B不要カテゴリの列挙（`_SKIP_B_CATEGORIES`）

```python
_SKIP_B_CATEGORIES: set[str] = {
    "役員・人事",           # #35
    "資金調達（社債・借入）", # #37
    "株主総会",             # #39
    "資産取得（不動産）",    # #40

    "開示事項の経過・変更",   # #48
    "子会社からの配当受領",   # #49
    "格付",                # #51
}
```

3. 要否が変わる場合は `_SKIP_B_CATEGORIES` も更新
4. **このファイル（006_tdnet_category_classification.md）も同時に更新**
