# 株主優待 構造化加工プロンプト

**用途**: 中間JSONL → 加工済みJSONL への変換指示。Claude Code直接 / Codex委任 両方で使用。
**親知見**: `docs/knowledges/tools/098_yutai_scraper.md`

## 入力

中間JSONL。各行:
```json
{"ticker": "9936", "name": "王将フード", "kenri_kakutei": "3月末、9月末", "yutai_text": "≪優待内容≫\n..."}
```

## 出力

加工済みJSONL。各行に `yutai_content`（整形済み優待内容テキスト）を追加:
```json
{"ticker": "9936", "name": "王将フード", "kenri_kakutei": "3月末、9月末", "yutai_content": "株主優待券(500円券) 必要株数：100 100:2,000円分 ..."}
```

## 加工手順（2段階抽出）

### Pass 1: 優待品名・ティア構造の抽出

`yutai_text` を読み、以下を抽出:

- 優待品の品名・金額・数量
- 株数ティア別の内容（`100:XXX 500:YYY` 形式）
- 随時優待（「随時」プレフィックス付き）
- 複数選択肢は `(1)Xまたは(2)Y`
- ティア内の選択は「または」、複合は「および」
- 異なる優待種別は4スペース区切りで独立セクション
- 見学会・抽選等は独立セクション

**Pass 1では保有条件の記載は不要。** ティア構造に保有期間が組み込まれている場合（例: `1年以上:1,000円、3年以上:3,000円`）はそのまま含める。

### Pass 2: 継続保有条件・権利判定方法の抽出

`yutai_text` を読み、以下を抽出:

- 継続保有条件（株数・期間・具体的な判定方法）
- 権利判定の具体的方法（「同一株主番号で連続N回以上記載」等）

**Pass 2ではティア内容は不要。保有条件・判定方法のみ抽出。** 株数条件を含む全要素を生データから忠実転記する。

### マージ

1. Pass 1 の出力を基本構造とする
2. Pass 2 の保有条件を各セクション末尾に※注記として付加
3. 保有期間×株数の二次元ティアの場合: Pass 1 がティア構造に保有期間を含め、Pass 2 が権利判定方法を補完

## フォーマットルール

### 出力形式

- 1レコード = 1行テキスト
- セクション区切り: 4スペース
- ティア: `必要株数：N N1:内容1 N2:内容2`
- 継続保有条件: セクション末尾に `※` で付記
- 権利判定方法: `※` で独立記載（ティア内に保有期間があっても省略しない）
- 利用条件・補足: `※` で付記、複数は `◆` 区切り
- 5年以上の増額: ティア行列ではなく `※` ノート
- 将来の制度変更: `※` で付記
- 随時優待: 「随時」プレフィックス
- `?` マーク: 文脈から推定して置換、推定不能なら除去

### 除去対象

以下はノイズとして除去する:

- 贈呈時期（`贈呈時期：...`、`≪贈呈時期≫`）
- 送付先情報（`≪送付先≫`）
- 免責文言（`●株主優待情報を...`）
- 日付表記（`（2026年4月21日現在）`）
- 写真キャプション（`［写真1］※写真は...`）
- 適用時期セクション（`【適用時期】...`、`【適用実施日】...`）
- 権利確定月・基準日の記述（`※年N回(X月・Y月)` 等）
- 自明な利用条件（`新規・既存問わず` 等）
- ランキング・メニュー等のページUI要素
- `アクセスランキング` 以降のテキスト全体
- `●株主優待情報を投資の判断材料` 以降の免責テキスト

### 複数権利確定月の処理

- 月ごとに優待内容が異なる場合: 各月の内容を切り出して個別の `yutai_content` を生成
- 全月共通の場合: 同じ `yutai_content` を使用（シート振り分けは Excel 生成スクリプトが行う）
- `～変更前～` / `～変更後～` がある場合: 現在適用される方を使用

## 出力例

### 入力（1381 アクシーズ）
```
kenri_kakutei: 6月末
yutai_text: ≪対象株主≫\n毎年6月30日現在の株主名簿に記載された500株以上保有の株主\n\n≪優待内容≫\n500株以上　自社製品...チキン加工食品...3,000円相当）\n...
```

### 出力
```
yutai_content: チキン加工食品セレクション(3,000円相当) 必要株数：500 ※「薩摩ハーブ悠然どり」使用
```

### 入力（1788 三東工業社）
```
kenri_kakutei: 6月末
yutai_text: ...QUOカード...\n1,000株未満 1年未満:1,500円 1年以上:3,000円\n1,000株以上 1年未満:3,000円 1年以上:6,000円\n...同一の株主番号で連続して2回以上記載...
```

### 出力
```
yutai_content: QUOカード 必要株数：100 100:1年未満1,500円/1年以上3,000円 1000:1年未満3,000円/1年以上6,000円 ※1年以上継続保有の確認は、毎年6月30日時点の株主名簿に同一の株主番号で連続して2回以上記載または記録された株主とする
```

## Codex委任時の追加指示

- 入力JSONLパスと出力JSONLパスを引数で受け取る
- 1レコードずつ処理し、逐次出力JSONLに追記する
- 処理完了時、伝言板に完了報告＋出力JSONLパスを記載
- 必要ライブラリ: なし（標準ライブラリのみ）
- Excel生成は `scripts/generate_yutai_excel.py` を別途実行
