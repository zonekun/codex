# 092: 外部リファレンス管理

`docs/references/` に外部ソース（Web記事・論文・ツイート・書籍等）の原文をそのまま保管する。
`docs/knowledges/` が自分たちの知見・ノウハウであるのに対し、こちらは**外部の一次情報をそのまま保存**する場所。

---

## 保存先・命名規則

| ソース種別 | 保存先 | 命名規則 |
|-----------|--------|----------|
| ツイート・X投稿 | `tweets/` | `YYYYMMDD_アカウント名_スラッグ.md` |
| Webページ引用 | `web/` | `YYYYMMDD_スラッグ.md` |
| 論文PDF（付随資料） | メイン資料と同じフォルダ | `{著者名}{年}_{識別子}.pdf` |
| 書籍・文書の画像 | `{トピック名}/` | `pageN.jpg` |
| GitHub/Qiita等のツール・ライブラリ | `{ツール名}/` | `README.md`（概要）+ 原文ファイル群 |
| 動画（YouTube等） | URLのみ記録（本体は保存しない） | — |

---

## 付随資料（論文PDF等）の保管ルール

メインのリファレンスMDが引用・言及している論文PDF・データセット・補足資料を保管する場合。

### 命名規則

```
{著者名}{年}_SSRN-id{番号}.pdf
{著者名}{年}_{識別子}.pdf
```

例：
- `Faber2007_SSRN-id962461.pdf`（Faber 2007, SSRN論文）
- `Asness2013_SSRN-id2174501.pdf`（Asness et al. 2013, SSRN論文）

### 配置先

メインのリファレンスと同じフォルダに配置する（`web/` 内の記事に付随する論文なら `web/` に置く）。

### ToC登録

`docs/references/README.md` の Table of Contents に**サブ番号**で登録する：

```
| 3a | [Faber2007_SSRN-id962461.pdf](...) | 説明 | #3 regime |
| 3b | [Asness2013_SSRN-id2174501.pdf](...) | 説明 | #3 factor_composite |
```

- 親番号 + アルファベット（a, b, c...）で付番
- `Cited in` 列に親番号と、関連するセクション/プラグイン名を記載
- Description は「著者 (年) "タイトル". 一行要約」の形式

### 保管判断基準

以下に該当する場合に付随資料として保管する：

1. メインのリファレンスMD内で手法・モデルの根拠として引用されている
2. 再現実装や検証時に原文参照が必要になる可能性がある
3. Web上で恒久的にアクセスできる保証がない（SSRN等は残るが念のため）

## Table of Contents 管理

`docs/references/README.md` が ToC（目録）を担う。

### 通し番号ルール

- メインエントリ: 連番（1, 2, 3, ...）
- 付随資料: 親番号 + アルファベット（3a, 3b, ...）
- フォルダ見出し行は `**tweets/**` 等で挿入（番号なし）

### 表示ルール

- **一覧表示時は通し番号（#列）をそのまま使う**。要約・圧縮のために番号を振り直さない
- ユーザーが「#N」で参照するため、番号のずれは誤操作に直結する

### 各列の記載内容

| 列 | 内容 |
|----|------|
| `#` | 通し番号 or サブ番号 |
| `File` | ファイル名（相対リンク） |
| `Description` | 一行要約。論文は「著者 (年) "タイトル". 要約」 |
| `Cited in` | 知見ファイル名 or 親番号+セクション名 |

---

## 新規登録の手順

1. ファイルを適切なサブフォルダに配置
2. `docs/references/README.md` の ToC に行を追加（§フォルダ一覧も新規フォルダなら追加）
3. 知見ファイルから引用する場合は `Cited in` 列に知見ファイル名を記載

## 検索のヒント

各トピックフォルダの `README.md` にキーワードセクションを設けているので横断検索できる。

```bash
grep -rl "EDINET" docs/references/
```
