# マーケットデータから成長率ごとの適切なPERを探ってみた

- **出典**: バフェット・コードマガジン
- **URL**: https://www.buffett-code.com/articles/13655
- **取得日**: 2026-04-13

---

## 現状の上場会社のPER

- 多くの企業がPER 8〜12倍で推移
- PER 16倍以下の企業が約6割
- **PER中央値: 13.6倍**

## 利益成長率とPERの関係

### 全銘柄による初期的分析（約3700社）

- 過去3期の実績 + 当期会社予想を用いた成長率
- 成長率10%刻みでグループ化
- **結果: 成長率がプラスの部分でも、EPS成長率が高くなってもPERが高くなる傾向が見られなかった**

### 右肩上がりにならない要因

1. **円安の影響**: 2022-2024年の一貫した円安で海外業績がかさ上げ。市場は将来の一方的円安を織り込まないためPERは低く評価
2. **景気循環株の影響**: COVID-19ボトムからの回復で成長率が高く出過ぎ
3. **EPSの特殊要因**: 減損等で過去成長率が歪む

### 安定成長銘柄に絞った分析（約200社）

**条件**:
- 上場日が2000年以降
- 過去3年間 + 当期予想のいずれも増益

**成長率 = 前期決算に対する会社業績予想の成長率**（実績は特別事象の影響を受けすぎるため）

| 成長率レンジ | PER中央値 | PER単純平均 | データ数 |
|-------------|----------|------------|---------|
| 0%-10% | 12.4 | 13.9 | 101 |
| 10%-20% | 15.0 | 17.4 | 62 |
| 20%-30% | 14.3 | 19.3 | 30 |
| 30%-40% | 18.6 | 24.0 | 13 |

**回帰式（EPS成長率ベース）:**

```
PER = 21.278 × EPS成長率 + 13.991
```

| 成長率 | 適正PER |
|--------|---------|
| 0% | 13.99倍 |
| 10% | 16.12倍 |
| 20% | 18.25倍 |
| 30% | 20.37倍 |
| 40% | 22.50倍 |

> 決定係数が非常に低くモデル精度は低い。参考程度

### 売上成長率ベースの分析

**条件**: 上場2000年以降 + 4期連続増収（前期赤字・翌期EPS 50%超下落は除外）

| 成長率レンジ | PER中央値 | PER単純平均 | データ数 |
|-------------|----------|------------|---------|
| 0%-10% | 13.0 | 16.1 | 251 |
| 10%-20% | 14.5 | 18.2 | 233 |
| 20%-30% | 14.5 | 21.2 | 107 |
| 30%-40% | 23.3 | 24.5 | 26 |
| 40%-50% | 22.8 | 30.5 | 16 |

**回帰式（売上成長率ベース）:**

```
PER = 23.732 × 売上成長率 + 14.889
```

| 成長率 | 適正PER |
|--------|---------|
| 0% | 14.89倍 |
| 10% | 17.26倍 |
| 20% | 19.63倍 |
| 30% | 22.01倍 |
| 40% | 24.38倍 |

> EPS成長率ベースよりも明確に成長率とPERが連動する傾向

## 結論

- 30%成長が続いていてもPERは20倍ちょっとでしか評価されていない
- 現状のマーケット環境では成長に対して非常にシビア
- **PEGレシオ1倍以下（PER倍率 < EPS成長率%）が一定の割安水準**
