# LLMを用いた株式投資戦略の自動生成におけるフィードバック設計

## 概要

LLMに投資戦略を反復改善させる際、フィードバック設計（何をどう見せるか）がパフォーマンス改善にどう影響するかを実証。
- パフォーマンス改善幅はモデル選択が支配的（Claude > Gemini > GPT）
- フィードバック設計は改善の「方向性」を決めるが、到達水準への影響は限定的
