## 仮説

**Polymarket のオッズ変動は株式市場の価格に先行する**
→ 政治・地政学イベントで予測市場の急変を検知したら、関連セクター/銘柄にエントリー

### 実装の流れ（ツイート主の構成）

1. Polymarket CLI で市場オッズをポーリング監視
2. 閾値（±6% 等）超の変動を検知
3. 関連銘柄（例: 地政学リスク → 航空・エネルギー）を自動マッピング
4. moomoo 証券 OpenAPI でペーパートレード自動発注

## 本プロジェクトでの検討観点

### 使えそうなポイント
- イベント駆動シグナルとしての予測市場オッズ利用
- 日本株でも地政学・政治イベント感応度の高い銘柄（防衛・原油関連・商社等）の先行シグナルになる可能性
- `docs/knowledges/tools/053_prediction_market_bot_ideas.md` のアイデアに具体例を追加できる

### 検証すべき疑問
- **先行性のエビデンス**: イラン空爆前のオッズ変動は後知恵の可能性。他の過去イベントで系統的に先行しているかバックテスト必須
- **銘柄マッピングの恣意性**: 「Israel x Hezbollah → AAL」の紐付けは妥当か？航空株全体が動くのか、個別 AAL なのかは別問題
- **変動閾値 ±6% の根拠**: 市場の流動性・板厚により意味が変わる。低流動性市場ではノイズで頻発するはず
- **インサイダー疑惑の裏返し**: もし実際にインサイダーで動いているなら、追随は一般人の情報劣位を拡大するだけの可能性
