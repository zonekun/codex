# 部分空間正則化付き主成分分析を用いた日米業種リードラグ投資戦略

**著者**: 中川 慧（大阪公立大学／松尾研）、竹本 悠城、久保 健治（東大／松尾研）、加藤 真大（みずほDL FT／大阪公立大学）
**掲載**: 人工知能学会 金融情報学研究会 SIG-FIN-036-13
**原文PDF**: [paper.pdf](paper.pdf)

## 1行サマリ

取引時間帯の非同期性（米国→日本）を利用し、米国セクターETFの当日Close-to-Closeリターンから、日本セクターETFの翌営業日Open-to-Closeリターンを「部分空間正則化付きPCA」で予測するロング・ショート戦略。単純モメンタム／正則化なしPCAを大きく上回り、Carhart4α=22.23%/yr（t=6.73）、MDD=9.58%、R/R=2.22を達成。

## キーワード

`リードラグ`, `日米セクターETF`, `Select Sector SPDR`, `TOPIX-17`, `部分空間正則化PCA`, `低ランク線形予測器`, `BLP (Best Linear Predictor)`, `Close-to-Close → Open-to-Close`, `ロングショート`, `Carhart 4ファクター`

## 仮説とデータ

- **仮説**: 米国市場で時点 t に確定した業種別情報は、日本市場の翌営業日 t+1 の日中リターン（Open→Close）に波及する
- **米国側（情報源）**: Select Sector SPDR ETF 11銘柄（XLB/XLC/XLE/XLF/XLI/XLK/XLP/XLRE/XLU/XLV/XLY）の Close-to-Close リターン
- **日本側（投資先）**: NEXT FUNDS TOPIX-17 業種別 ETF 17銘柄（1617.T〜1633.T）の Open-to-Close リターン
- **期間**: 2010-01 〜 2025-12。日米共通営業日のみ
- **ウィンドウ長**: L=60営業日

## 手法: 部分空間正則化付きPCA

### 3.1 事前固有ベクトル V₀ ∈ ℝ^(N×3)（K₀=3）

日米結合（N=28）に対して3本の経済的に意味のある直交ベクトルを構築:

1. **グローバルファクター**: v₁ ∝ 1（全銘柄等ウェイト）
2. **国スプレッドファクター**: v₂ ∝ (1_NU, -1_NJ) を v₁ に直交化
3. **シクリカル/ディフェンシブファクター**:
   - 米国シクリカル: XLB, XLE, XLF, XLRE
   - 米国ディフェンシブ: XLK, XLP, XLU, XLV
   - 日本シクリカル: 1618.T, 1625.T, 1629.T, 1631.T
   - 日本ディフェンシブ: 1617.T, 1621.T, 1627.T, 1630.T
   - 符号ベクトルを v₁, v₂ に直交化

### 3.2 正則化相関行列

長期サンプル（2010-01〜2014-12）から C_full を推定し:

```
D₀ := diag(V₀ᵀ C_full V₀)                        （事前固有値）
C_raw := V₀ D₀ V₀ᵀ                                （ターゲット行列）
C₀ := Δ^(-1/2) C_raw Δ^(-1/2),  Δ = diag(C_raw)   （相関行列化）
C_t^reg := (1-λ) C_t + λ C₀,  λ = 0.9             （Ledoit-Wolf型縮約）
```

C_t^reg を固有分解し、上位 K=3 の固有ベクトル V_t^(K) を取得 → 米国ブロック V_U,t^(K) / 日本ブロック V_J,t^(K) に分割。

### 3.3 リードラグシグナル（低ランク線形予測器）

```
f_t := V_U,t^(K)ᵀ z_U,t            （米国ショックをK次元部分空間へ射影）
ẑ_J,t+1 := V_J,t^(K) f_t           （日本側ローディングで復元）
       = B_t^(K) z_U,t,  B_t^(K) := V_J,t^(K) V_U,t^(K)ᵀ
```

z_U,t は米国セクターの標準化Close-to-Closeリターン。rank(B_t^(K)) ≤ K の**低ランク線形予測器**として解釈できる（命題1）。

### 理論的裏付け（命題2）

理想化モデル z_U,t = V_U⋆ g_t + ε_U,t、z_J,t+1 = V_J⋆ g_t + ε_J,t+1 の下で、BLP（最良線形予測）は:

```
B⋆ = Σ_JU Σ_UU^(-1) = (1/(1+σ_U²)) V_J⋆ V_U⋆ᵀ
```

となり、命題1の B_t^(K) と同型の射影/復元構造。部分空間正則化PCAはこの V_U⋆, V_J⋆ を安定推定する手段。

## ポートフォリオ構築

- シグナル s_j,t := ẑ_j,t+1 で日本銘柄をランキング
- 上位30% をロング、下位30% をショート、等ウェイト（市場中立）
- |w|_1 = 2、Σw = 0

## 4.4 実証結果

### 戦略比較（2010-2025）

| Strategy | AR(%) | RISK(%) | R/R | MDD(%) |
|---|---|---|---|---|
| MOM（単純モメンタム） | 5.63 | 10.59 | 0.53 | 16.97 |
| PCA_PLAIN（λ=0） | 6.24 | 9.94 | 0.62 | 23.65 |
| **PCA_SUB（提案）** | **23.79** | **10.70** | **2.22** | **9.58** |
| DOUBLE（MOM×PCA_SUB 2×2ソート） | 18.86 | 11.16 | 1.69 | 12.10 |

### リスク調整後α（Fama–French 3 / Carhart 4）

| Strategy | FF3 α(%/yr) | FF3 t | C4 α(%/yr) | C4 t | C4 WML |
|---|---|---|---|---|---|
| MOM | 3.89 | 1.23 | 3.54 | 1.17 | **+0.268*** |
| PCA_PLAIN | 4.39 | 1.34 | 4.43 | 1.36 | -0.029 |
| **PCA_SUB** | **22.17*** | 6.69 | **22.23*** | 6.73 | **-0.047*** |
| DOUBLE | 17.11*** | 5.11 | 16.77*** | 5.02 | +0.132*** |

- PCA_SUB は Adj.R² ≈ 0.004–0.006 と極めて低く、既存スタイルファクターでは説明されない収益源泉
- **WML係数が負**である点が重要: 単純なモメンタム追随ではなく、情報伝播に伴う相対的な価格調整から収益が生じている証左
- DOUBLE は WML に正の有意エクスポージャーを持つため、提案手法の純粋性は劣化する

## なぜ「正則化なしPCA」では駄目か

短ウィンドウ（L=60）で相関行列を推定すると固有空間が不安定化し、シグナル分散が膨らむ。事前部分空間への縮約（λ=0.9）が推定誤差を抑え、予測性能を改善する（Ledoit-Wolf [22], 中川ら[18] と同じ思想）。

## このワークスペースへの示唆・実装メモ

### 投資戦略としての実装可能性

- **オーバーナイトギャップを跨がない**: 日本側は「寄付→引け」の日中リターンのみを取るので、米国→日本のギャップリスクを回避できる
- **必要データ（既存リソースで揃う）**:
  - 米国セクターETF 11銘柄の日次Close: yfinance（`docs/knowledges/api/004_yfinance_index_tickers.md`）
  - 日本セクターETF 17銘柄のOpen/Close: J-Quants daily_quotes（`docs/knowledges/api/001_jquants_api.md`）
  - または 日米共通営業日マスタは TDnet 営業日と同じロジック
- **計算コスト**: 28×28 相関行列 × 60日ウィンドウ × ~2600日 程度。Python でローカル再現可能
- **シクリカル/ディフェンシブ分類**: 著者の分類をそのまま使うか、GICS + TOPIX-17 の属性から再生成するか要検討

### バックテスト設計上の注意（`skills/backtest_design.md` 準拠）

- 執行スリッページ・板の薄さ（特にTOPIX-17 ETFの1622.T〜1633.T系）を必ず加味
- 2010–2014 は C_full の推定窓、2015–2025 をアウトオブサンプルで再評価すべき
- 月次換算ではなく日次リターンで Newey-West ラグ調整を行う（論文と同様）

### 類似戦略との関係

- `docs/knowledges/analysis/` 内のクロスマーケット系戦略を要確認
