# F5 翌期OP変化・コンセ乖離 NaN バグ（2379 ディップ起点）

**対象ファイル**: `scripts/earnings_model/earnings_model_predict.ipynb` セル5（1-1〜1-6）＋ セル7（compute_score）
**発覚**: 2026-04-14 発表分の反省会で 2379 ディップ（FY発表）の next_year_op_change / consensus_deviation が NaN

## 症状

2379 ディップ FY 決算の prediction JSON:

```json
{
  "ticker": "2379",
  "quarter": "FY",
  "score": -1,
  "prediction": "NEUTRAL",
  "reasons": "YoY OP -59%",
  "yoy_op": -0.59,
  "next_year_op_change": NaN,
  "consensus_deviation": NaN,
  "baseline_yoy_op": 0.0952
}
```

- `next_year_op_change=NaN` → 来期予想（`NxFOP`）が取れていない
- `consensus_deviation=NaN` → コンセンサス NEXT が取れていない or 計算失敗
- 結果: F5（翌期OP変化）と F4（コンセ乖離）が無効化され、大ネガ材料が捕捉されず score=-1 NEUTRAL で終わった

## ユーザーが手動確認した正解値

- 次期年間予想 / 今年度実績 = **81%**（-19%減益）
- 次期年間予想 / NEXTコンセ = **64%**（-36%下振れ）

本来なら F5（翌期-19%）と F4（対NEXTコンセ -36%）で複合的に -3〜-5 score 程度のネガになるはず。実績も -9.4% DOWN だった → DOWN予測的中だったはず。

## 影響範囲

**FY発表銘柄** で next_year_op_change / consensus_deviation が NaN になっているレコードは 2379 以外にもある可能性。全件サーベイ必要。

`scripts/earnings_model/earnings_model_predict.ipynb` には 2026-04-14 のコメント:
```python
# FY発表時はNEXT（来期）コンセと会社来期予想の乖離を使う
# （7516コーナンのバグ修正, 2026-04-14）
```
があり、FY発表のNEXT処理は最近追加された。そこの実装漏れ・条件分岐ミスの可能性。

   - J-Quants `get_fin_summary('20260414')` の 2379 行を確認

4. 2026-04-14 発表分の FY 銘柄全体で F4/F5 NaN 率を算出 → 体系的バグか個別問題かを切り分け

## 期待される修正

- NEXT コンセ不在時の挙動明示化（NaN維持 or CURRENTで代替）

## 実装した修正（2026-04-16）

### 原因

2026-04-14 発表分 FY 84件のうち、NxFOP が NA なのは 6件（7.1%、来期予想未開示パターン）。F4 consensus_deviation の NaN は 64件（76.2%）で、主因はこれら未開示銘柄 + CONSENSUS.TARGET='NEXT' のデータ欠如。2379 ディップは「来期予想未開示」の典型例で、fin_summary の NxFOP/NxFOdP/NxFNp がすべて NA。

### 修正内容

1. **F4 `consensus_deviation` に CURRENT フォールバック追加** (`earnings_model_predict.ipynb` Cell5)
   - FY で NxFOdP が NA の場合、今期実績 OdP vs CURRENT コンセンサスで代替比較
   - 新規フィールド `f4_source`（`FY_NEXT` / `FY_CURRENT_fallback` / `Q_CURRENT`）をpredictionに記録
   - 2379 ディップで試算: OdP 8,990M vs CURRENT 9,817M → -8.4% → F4=-2、F3 と合算で score=-3 (DOWN)

2. **F5 欠損メッセージ明示化** (Cell7 compute_score)
   - FY で来期予想未開示の場合、reasons に「来期予想未開示 (F5/F7/F12無効)」を追記
   - 新規フィールド `next_year_disclosed: bool` をpredictionに記録

3. **prediction JSON 拡張**: `f4_source` / `next_year_disclosed` 列追加（次回予測以降に反映）
