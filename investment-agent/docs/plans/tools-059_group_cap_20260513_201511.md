## 問題の構造

### 根本原因: 同一変数の多重使用

`next_year_op_change` という1つの数値を F5a・F7・F12(FY) の3因子が独立に読み、それぞれスコア加算している。OP増益ならEPS増益も通常連動するためF5bも同方向に発火。結果「来期ガイダンスが良い」という1つのニュースで最大 +7。

同様に非FYでは `yoy_op` を F3・F12(非FY) が共有し、黒字転換(F15)も同じOP実績に由来。「今期OPが良い」という1つの事実で最大 +5。

F4(コンセンサス乖離)は `max(|F4a|,|F4b|)` で同問題を既に解決済み。同じ思想を来期見通し系・当期業績系に適用する。

### 二重加算ペア一覧

| グループ | メンバー | 共有変数 | 最悪合計(現行) |
|----------|---------|---------|---------------|
| 来期見通し (FY) | F5a, F5b, F7, F12(FY) | `next_year_op_change`, `next_year_eps_change` | +7 / -8 |
| 当期業績 (全Q) | F3, F12(非FY), F15 | `yoy_op` | +5 / -4 |
| コンセンサス | F4a, F4b | `consensus_deviation`, `np_consensus_deviation` | **対策済み** |

### P1-1. 来期見通しグループキャップ ±3 導入 + F5a縮小 ⚠️

**症状**: FY決算で来期OP+30%・来期EPS+30%・PER10x・baseline+5%の企業に対し、F5b(+2)+F5a(+2)+F7(+1)+F12(+2)=+7が付与される。「来期ガイダンスが良い」という1つのニュースに対してスコアが過大。F4(コンセ乖離)の最大+3を大幅に上回り、因子間の影響力バランスが崩壊している。

**該当**: `scripts/earnings_model/earnings_model_core.py:L105-201` / `compute_score()` 内 F5a, F5b, F7, F12

```python:L114-128

            _f5a_sign_ok = (not _f5b_valid
```

**根本原因**: 各因子が独立に `score` へ加算する設計で、因子間の相関を考慮していない。F4では `max(|a|,|b|)` で対策済みだが、F5/F7/F12に同等の仕組みがない。

**修正方針**:

1. グループ蓄積変数 `_guidance_group` を導入
2. F5b/F5a/F7/F12(FY) の加算先を `score` → `_guidance_group` に変更
3. F5a のスコアを ±2 → ±1 に縮小（従因子の位置づけ強化）
4. 全因子計算後に `clamp(-3, +3)` して `score` へ加算
5. F5の翌期予想非開示ペナルティ(-1)は `score` に直接加算（グループ外。レビュー#2採用: 「ガイダンスの不在」は内容評価と別次元）
6. キャップ発火時は `reasons` にキャップ適用行を追加（レビュー#1採用: `"来期見通しキャップ ({raw:+d}→{capped:+d})"` 形式）

```python
def compute_score(row: pd.Series) -> tuple[int, list[str]]:
    score = 0
    reasons: list[str] = []
    _guidance_group = 0    # FY来期見通し: F5a+F5b+F7+F12(FY)
    _performance_group = 0  # 当期業績: F3+F12(非FY)+F15
    cur_per: str = row["quarter"]
    ...

    # F3 → _performance_group +=
    # F4 → score +=           (独立: コンセンサスは別次元)
    # F5a → _guidance_group += (±1に縮小)
    # F5b → _guidance_group +=
    # F5非開示 → score +=     (独立: ガイダンスの不在は内容評価と別次元)
    # F6 → score +=           (独立: 出尽くしリスク)
    # F7 → _guidance_group +=
    # F8 → score +=           (独立: 記念配当)
    # F10 → score +=          (独立: 自社株買い)
    # F11 → score +=          (独立: 増配/減配)
    # F12(FY) → _guidance_group +=
    # F12(非FY) → _performance_group +=
    # F13 → score +=          (独立: qoq_op は別変数)
    # F14 → score +=          (独立: 株式分割)
    # F15 → _performance_group +=
    # F16 → score +=          (独立: FY未達)

    # グループキャップ適用（キャップ発火時はreasonに明記）
    _capped_g = max(-GUIDANCE_CAP, min(GUIDANCE_CAP, _guidance_group))
    if _capped_g != _guidance_group:
        reasons.append(f"来期見通しキャップ ({_guidance_group:+d}→{_capped_g:+d})")
    score += _capped_g

    _capped_p = max(-PERFORMANCE_CAP, min(PERFORMANCE_CAP, _performance_group))
    if _capped_p != _performance_group:
        reasons.append(f"当期業績キャップ ({_performance_group:+d}→{_capped_p:+d})")
    score += _capped_p

    return score, reasons
```

### グループ外因子（独立のまま）

| 因子 | 理由 |
|------|------|
| F1 (進捗率) | 期中実績。ガイダンスとは異なるシグナル |
| F2 (業績修正) | 修正の有無。YoYとは異なるイベント |
| F4 (コンセ乖離) | 市場期待との差。グループ内で対策済み |
| F6 (出尽くしリスク) | F1+F2の組合せだがネガティブ専用 |
| F8 (特別配当) | 還元施策。業績指標とは別 |
| F10 (自社株買い) | 還元施策 |
| F11 (増配/減配) | 配当政策。OP成長とは別の経営判断 |
| F13 (QoQ OP) | `qoq_op`（前Q比）で `yoy_op` とは別変数 |
| F14 (株式分割) | 資本政策 |
| F16 (FY未達) | 達成率。来期見通しとは別 |
