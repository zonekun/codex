## 変更サマリ

### 出力仕様（v1 → v2）

| 項目 | v1 | v2 |
|------|----|----|
| 形式 | CSV (SJIS) | **Excel (.xlsx)** |
| 列構成 | code, name, data, matsui_raw | **権利月, TICKER, 会社名, 優待内容** |
| ファイル構造 | 月別CSV | **1ファイル、シート `01`〜`12`（月別）+ `随時`** |
| 出力先 | `Dropbox\stock\temp\yutai\` | **`C:\Users\zonekun\Dropbox\stock\優待\`** |
| 権利月表記 | なし | `X月末`（月末）/ `X月XX日`（月中）|

### 権利月の表記ルール

- 月末基準日: `6月末`（`6月30日` とは書かない）
- 月中基準日: `5月15日`, `5月20日` 等そのまま
- 複数月: 1銘柄が複数シートに出現（例: 3月末・9月末 → シート `03` と `09` に各1行）
- 随時優待: シート `随時` に格納
- ソース: 生データの `kenri_kakutei` フィールドから抽出

### kenri_kakutei → シート振り分けルール

`kenri_kakutei` は自由テキスト（例: `3月末、9月末`, `6月末`, `4月20日` 等）。以下の手順でシート番号に変換:

1. テキストを `、` `，` `,` で分割 → 各権利確定日ごとに処理
2. 各要素から月番号を抽出: `(\d{1,2})月` にマッチ → 2桁ゼロ埋め（`6月末` → `06`）
3. マッチしない or 「随時」→ シート `随時` に振り分け
4. 1銘柄が複数月にマッチ → 各シートに1行ずつ出力（同一内容）
