## 根本パターン（10社分まとめ）

1. **pdfplumber テーブル検出不可**（罫線なし） → Gemini PDF 直接（3160）
2. **アダプター設定ミス**（unit_scale 誤設定） → 除去・修正（9973）
3. **プレフィックスとセクションの部分一致不足** → マッチロジック改善（3608）
4. **1セルに複数値が結合** → Gemini PDF 直接（2294, 4058）
5. **セル結合による多列テーブル** → Gemini PDF 直接（7564）
6. **最新PDFに対象月データがない**（空欄） → 対象月のPDF個別取得（7545, 3549, 7445）
7. **セクション拡張で解決済み** → 再抽出で改善見込み（7562）
