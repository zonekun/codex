## 調査方法

### 原則
**1社ずつPDFを読んで逆引き。バッチ処理・推定・Gemini逃げ禁止。**

CSVデータだけで原因を推定してPDF読みを省略することは絶対禁止。「小差だから速報/確報差だろう」と推定で片付けず、必ずPDFで確認してから判断する。

### 手順

1. **CSVデータ取得**: `bc_compare_ng_*.csv` から対象tickerのNG行を抽出。our_value, bc_value, yoy_offset, diff を確認
2. **PDF取得**: `C:\Users\zonekun\Dropbox\stock\temp\ng_monthly_docs/` にダウンロード済みPDFがある。ない場合はGCSから取得
3. **PDFを読む**: Claude CodeのRead toolでPDFを開き、テーブル構造・値を目視確認
4. **BC値の逆引き**: BCの値がPDFのどの行・どの列にあるかを特定し、正しいことを確認（✓）
5. **our値の逆引き**: ourの値がPDFのどこから来たかを特定。「上期テーブルの8月列」「前期テーブルの値」等、具体的な位置を記載
6. **原因特定**: なぜ誤った値が抽出されたかをパターン分類
7. **対策記載**: adapter修正で済むか、コード修正が必要か、対象外かを判断
8. **都度保存**: 1社完了ごとに計画ファイルに追記。まとめて後から書かない

### 記録フォーマット

```
### {ticker} {社名}（{NG件数}件NG）
- **NG内容**: {フィールド名} our={値} vs BC={値} (diff={値})
- **逆引き（{月}度PDF）**: BC {年月} {フィールド}={値} → PDF {テーブル名} {月}列={値} ✓。our={値} → **{誤取得元の具体的位置}**
- **原因**: {パターン名}。{詳細説明}
- **対策**: {adapter修正内容 / コード修正内容 / 対象外理由}
```

### 所要時間の目安
- 1社あたり5〜15分（PDF読み+逆引き+記録）
- 56社で約2セッション（各セッション25〜30社）
