# 索引ファースト強制リマインダ フック設計

**作成日時**: 2026-05-03 12:55 JST
**ステータス**: 実装済み
**起点**: MR-066（意志依存型ルール違反）

## 問題

CLAUDE.md §高頻度参照テーブルのルールがAIの意志に依存しており、コンテキスト圧縮後等に守られない。MR-066で5回以上のユーザー誘導が発生。

## 解決策

全プロンプトに1行リマインダを自動注入する UserPromptSubmit フック。キーワードマッピングは不要（漏れが出るため）。ルックアップロジックはCLAUDE.md側に既にあり、フックは「照合せよ」と言うだけ。

## 実装

- スクリプト: `scripts/keyword_md_gate.py`
- 出力: `[索引ファースト] 回答を検討する前にCLAUDE.md §高頻度参照テーブルを照合せよ`
- 登録: `.claude/settings.local.json` UserPromptSubmit 2つ目のフック
- コスト: 毎ターン約30トークン（会話全体の0.1%以下）

## 設計判断

| 検討案 | 採否 | 理由 |
|--------|------|------|
| キーワード → MD マッピング | 却下 | 高頻度参照テーブルの劣化コピー。保守二重化。漏れが出る |
| 全プロンプト1行リマインダ | 採用 | 漏れゼロ、保守不要、コスト無視可能 |
