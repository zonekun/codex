## 共通プロンプト改善案

多くのNGに共通する問題をベースプロンプトに反映すべき:

```
# 追加ルール案
7. 対象月の列が空欄（―、空白、ハイフン）の場合は、必ずnullを返してください。
   隣の月や前年度の値で代替しないでください。
8. テーブルが上期（4月-9月等）と下期（10月-3月等）に分かれている場合、
   対象月が含まれる方のテーブルから取得してください。
9. 「当期」「本年」テーブルと「前期」「前年」「参考」テーブルがある場合、
   必ず「当期/本年」テーブルから取得してください。
10. 売上高（絶対額）と前年同月比（%）は別の行/列です。混同しないでください。
```
