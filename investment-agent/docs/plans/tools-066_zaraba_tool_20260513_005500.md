    """自社株買い関連タイトルか判定（watch時の命綱）.

        return False

## 技術的な注意点

### watch 時の制約（重要）

watch ポーリング中は BQ にデータ未ロード。自社株買い開示の検知は **TDnet HTML 一覧のタイトル文字列のみ** が情報源。

→ `_is_buyback_title()` の品質が F10 の精度を直接左右する。  
→ Step 6 の BQ 大量検証で漏れ・誤検知を最小化してから本番投入。

### TDnet 自社株買い PDF の定型構造

```
1. 取得の理由
   株主還元の充実および資本効率の向上のため

2. 取得に係る事項の内容
   (1) 取得する株式の種類    普通株式
   (2) 取得し得る株式の総数  500,000 株
      （発行済株式総数（自己株式を除く。）に対する割合 3.2%）
   (3) 取得価額の総額        30 億円（上限）
   (4) 取得期間              2026 年 5 月 14 日～ 2026 年 11 月 30 日
   (5) 取得方法              東京証券取引所における市場買付
```

ToSTNeT-3 の場合:
```
   (5) 取得方法    東京証券取引所の自己株式立会外買付取引（ToSTNeT-3）
```

### 正規表現の設計方針

```python
# 割合（最優先 — PDF に直接記載されている）
RE_PCT = re.compile(r"発行済株式総数.*?に対する割合[^\d]*(\d+[.,]?\d*)\s*[%％]", re.DOTALL)

# ToSTNeT-3 / N-NET3（表記ゆれ対応: 半角/全角/混合 + 名証N-NET3）
RE_TN3 = re.compile(r"ToSTNeT[\s\-－]*[3３]|ＴｏＳＴＮｅＴ[\s\-－]*[3３]|N[\-－]NET[3３]|Ｎ[\-－]ＮＥＴ[3３]|立会外買付取引")

# 株数（フォールバック: 割合が取れない場合に SHARES_OUTSTANDING で計算）
RE_SHARES = re.compile(r"取得し得る株式の総数[^\d]*(\d[\d,，]*)\s*株")

# 金額（情報タグ用）
RE_AMOUNT = re.compile(r"取得価額の総額[^\d]*(\d[\d,，]*)\s*(百万円|億円|千円|円)")
```

### PDF 取得のエッジケース

- TDnet PDF URL は `Disclosure.document_url` に格納済み（リダイレクト解除済み）
- PDF が TDnet サーバーから取得不可の場合（404等）→ None 返却、フォールバック +2
