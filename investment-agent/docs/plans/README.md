# 作業計画 (docs/plans/)

このディレクトリには作業計画のmdファイルを保存する。

## 方針
- **Claude Code 標準の Plan mode (`/plan`) は使用しない**
- `skills/planning.md` スキルで本ディレクトリに計画を出力する
- 理由: Plan mode は `~/.claude/plans/` に自動命名で保存され、後から参照が困難なため

## ファイル命名規則
```
YYYYMMDD_HHMMSS_<slug>.md
```

## ステータス管理
各計画ファイルのヘッダにステータスを記載:
- **未着手**: 計画作成済み、作業未開始
- **進行中**: 作業中
- **完了**: 作業完了、振り返り記入済み
- **中止**: 作業を中止（理由を記載）
