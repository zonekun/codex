## Step 4: AI誤読リスクレビュー

### [MR-127-1] HIGH: P0-3の修正方針がBLOCKER未解決のまま残存

**該当行**: L116-165（P0-3本体）、L380-382（レビュー結果セクション）

**誤読シナリオ**: AIがP0-3のbefore/afterを読み、`OP_PROFIT`への全面統一を実装する。1Q/2Q/3QでF4cが不発火になる（IFIS由来のOP_PROFIT=NULL）。末尾のCR-126言及は「レビュー済み=解決済み」と解釈される可能性がある。

**推奨**: P0-3セクション内に「BLOCKER対応: 通期はOP_PROFIT（営業利益）、1Q/2Q/3QはORD_PROFIT（経常利益）を使う分岐を実装」の方針とbefore/afterコードを追記する。現行のbefore/afterは削除または「初期案（却下）」とマーク。

### [MR-127-2] MEDIUM: 整合性マトリクスがQ別利益種別分岐を反映していない

**該当行**: L339

**現状**: `F4c コンセ乖離 | **cumulative_op（営業）** | **OP_PROFIT（営業）** | 営業 vs 営業`

**誤読シナリオ**: 方針決定後の実装で「四半期は経常利益」とした場合、マトリクスの「営業 vs 営業」と矛盾し、AIがマトリクスに合わせて営業利益に戻そうとする。

**推奨**: F4cの行を「FY: 営業 vs 営業 / 1Q-3Q: 経常 vs 経常」に分割するか、注記を追加。

### [MR-127-3] MEDIUM: P1-3がP0-3の方針変更に連動未記載

**該当行**: L232-268

**誤読シナリオ**: P0-3でQ別分岐を導入した場合、P1-3の表示行も同じ分岐が必要。現プランではP1-3は無条件に`ORD_PROFIT`→`OP_PROFIT`と記載しており、P0-3と独立に実装すると表示とスコアリングで異なるロジックになる。CR-126 Finding-7でも指摘済みだが、プランMD内に連動注記がない。

**推奨**: P1-3に「P0-3の方針確定後に連動修正。P0-3がQ別分岐を導入する場合はP1-3も同じ分岐を適用」と注記。

### [MR-127-4] LOW: P0-2のOP_PROFITデータ可用性前提が暗黙

**該当行**: L93-103

**誤読シナリオ**: AIが「OP_PROFITは全銘柄で利用可能」と前提して実装し、NoneケースのテストをスキップするIFIS-only銘柄（QUICKカバーなし）でconsensus_nextのOP_PROFITがNoneになるケースの考慮漏れ。

**推奨**: P0-2の修正方針にNote「consensus_nextがIFIS FY由来の場合はOP_PROFIT=None。観察用フィールドのためNone返却で問題なし（CR-126 Finding-5確認済み）」を追記。

### [MR-127-5] LOW: F4cの閾値体系（非対称8段階）がプランから不可視

**該当行**: L120-155（P0-3のコード抜粋がL1814-1819のみ）

**問題**: 実コードL1823-1846ではF4cの閾値が`+10%→+3 / +5%→+2 / +0%→+1 / -5%→-2 / -10%→-3 / -20%→-4 / -30%→-5`の非対称8段階。プランのbefore/afterはL1818-1819の変数変更のみを示しており、閾値分岐コード（28行）は省略されている。修正自体は入力変数のみの変更で閾値には触れないため技術的には問題ないが、AIがF4cの影響度（最大+3/-5）を把握できないまま検証を行う可能性がある。

**推奨**: 必須ではないが、P0-3の「注意」セクションにF4cのウェイト範囲（+3/-5）を1行注記すると、検証時のスコア差分の妥当性判断が容易になる。
