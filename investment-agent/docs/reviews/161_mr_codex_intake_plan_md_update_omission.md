### 直接原因

- CLAUDE.md §4.3 の4点セット（知見MD + プランMD + memory + コミット）のうち「プランMD更新」を実行しなかった
- 083の取り込みフロー（§取り込みフロー L31-37）に「計画MD更新」が含まれていなかった。083は「成果物コピー → コードレビュー → 規約準拠確認」で完結しており、関連プランMDへの言及がない
- 伝言板エントリの必須フィールド（`from`, `to`, `status`, `task`）に「関連計画MD」が含まれていないため、取り込み時に計画MDの存在が自明でなかった

### 根本原因

- CLAUDE.md §4.3 は汎用ルール。083は外部成果物取り込みの具体手順。両者の間に**プランMD更新の導線が欠落**していた
- 083の取り込みフローが §4.3 の4点セットを参照・引用していない。具体手順（083）を実行するとき、汎用ルール（CLAUDE.md §4.3）の全要素を毎回想起する構造になっていない
