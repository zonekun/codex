- **トリガー**: 分割後に `discovery.py` 経由で `append_entry()` が呼ばれた時
- **影響**: 新規テーブルのカタログ登録がサマリテーブルの外に追記され、AIが新規テーブルを発見できない
- **根拠**: `src/datastore/catalog.py:39-41` — `open(CATALOG_PATH, "a")` でファイル末尾に追記
- **推奨対応**: (a) `catalog.py` の `append_entry()` を修正対象として Phase 3 に追加するか、(b) 「ほぼ未使用機能」であることを明示し、分割後に `append_entry()` を使用禁止にする旨を記載する。いずれの方針かを計画MD内で明確にする
