## 分析フェーズN: <フェーズ名>（ANALYZED_PASS / ANALYZED_FAIL）

### 使用データ ★必須

| 項目 | 内容 |
|------|------|
| データソース | MAFF / BigQuery STOCK_PRICE / J-Quants API / yfinance / etc. |
| 対象銘柄・セクター | 銘柄名とコード一覧（例: ゼンショーHD 7550）、またはセクター名（外食全社 等） |
| 粒度 | 日次 / 週次 / 月次 / 四半期 |
| 主要項目（列） | 終値・週次リターン・営業利益率 等、分析に使った列を列挙 |
| 期間 | YYYY/MM 〜 YYYY/MM（N週 / N件 / Nサンプル） |
| 前処理 | 差分化・標準化・白色化 等、生データから何を変換したか |

### 使用アルゴリズム ★必須

| アルゴリズム | 選択理由 |
|------------|---------|
| （例）Spearman相関 | 財務データは正規分布しないため、ランク相関を使用 |
| （例）AR(p)白色化 + CCF | 系列のACF≈0.96で自己相関が強く、見せかけの相関を防ぐため |
| （例）グレンジャー因果性 | 「XがYの未来を予測するか」方向性のある因果を検定するため |

> 選択理由には「なぜ他の手法ではなくこれを使ったか」を書く。
> 例: 「Spearmanではなく白色化CCFを使った理由: ACFが高く偽相関が生じるため」

|------|-----|------|
| （例）くら寿司 CCF lag1 | -0.191 | ★有意 |
| （例）グレンジャー p値（BH補正後） | 0.12 | 非有意 |
