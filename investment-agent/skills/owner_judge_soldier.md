# オーナー色判定ソルジャー（/owner-judge-soldier）

**種別**: Agent（独立実行→結果返却）
**作成日**: 2026-05-18

## 目的

指定ティッカーの発行会社が「オーナー色が強い（創業家・オーナー経営者が実質支配）」か否かを
WebSearch で調査し、**YES / NO 二択**で返す。

「オーナー色が強い」= 創業者一族または創業家が筆頭株主・経営実権・資産管理会社経由の支配
のいずれかを保持している状態。

**呼び出し形式**: Agent ツールで独立実行  
**入力**: プロンプトに以下の形式で渡す
```
TICKER=XXXX 会社名=YYYY の手順に従い判定せよ
```
**出力**: `YES` または `NO` から始まる1行 + 根拠1〜2行

---

## 手順

### Step 1: WebSearch で情報収集

以下のクエリを順に実行し、必要な情報が揃ったら次の検索は省略してよい:

1. `[会社名] 創業者 代表取締役 オーナー`
2. `[会社名] 筆頭株主 大株主 資産管理会社 持株会社`
3. （必要であれば）`[会社名] investor relations 大株主 site:ir.nikkei.co.jp OR site:strainer.jp`

収集する情報:
- 創業者・創業家の氏名（存在するか）
- 現代表取締役が創業家か（苗字一致、「創業者の子息」等の記述）
- 大株主リストに個人名・資産管理会社・興産会社・持株会社がいるか
- 親会社・外資・機関投資家のみが株主でオーナー系の痕跡がないか

### Step 2: 判定

**YES（オーナー色あり）** — 以下のいずれかを満たす:
- 創業者または一族が上位大株主（個人名 or 明らかに創業家系の資産管理会社名）
- 代表取締役・会長・オーナーが創業家一族（苗字一致 or 記事に明記）
- 「〇〇興産」「〇〇商事」「〇〇ホールディングス（非上場）」等の持株会社経由で創業家が支配

**NO（オーナー色なし）** — 以下のいずれかを満たす:
- 外資系企業・機関投資家・**上場**親会社が支配株主で創業家の存在なし
- 元々は創業家系だが完全にexitした旨の記載あり
- 上場子会社で親会社が明確（セグメント情報等に記載）かつその親会社も上場企業または外資
- 検索結果に創業家の痕跡が全くなく、サラリーマン経営と判断できる

> **重要**: 筆頭株主が**非上場**の持株会社・HD・興産・商事等の場合は「上場子会社」と判断せず、必ずその非上場会社の所有者を追加調査すること。非上場HDの背後に創業家がいればYES。

### Step 3: 出力フォーマット

判定は必ず以下のどちらかで始めること。冗長な前置きは不要。

```
YES: [会社名] はオーナー色あり。[根拠1〜2文]
```

または

```
NO: [会社名] はオーナー色なし。[根拠1〜2文]
```

---

## 注意事項

- 情報が乏しく判定困難な場合は `NO` として「情報不足により判定困難、デフォルトNO」と付記
- 親会社が外資系の場合は迷わず `NO`
- 上場子会社（有価証券報告書に親会社記載あり）は迷わず `NO`
- WebFetch で IR ページや有報のサマリーページを直接取得してもよい
