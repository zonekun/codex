# スキル: 日証金データ定刻取得

## 概要
日本証券金融（日証金）から逆日歩・品貸料・貸借データをスクレイピングで取得し、ローカルストレージに保存する。

## 使い方
```
日証金から逆日歩データを取得してストレージしてください
```

## 実装方針
- 日証金 (https://www.jsf.co.jp/) から銘柄別の貸借データを取得
- 1銘柄ずつ期間指定でダウンロードが必要（APIなし、手動だと非常に手間）
- Webスクレイピング（httpx + BeautifulSoup）で自動化
- Parquet形式で data/lake/nisshokin/ に保存
- 定刻実行（毎日18:00 JST）をスケジューラに登録

## 取得データ
- 品貸料（逆日歩）
- 貸株残高・融資残高
- 銘柄コード・日付

## 注意
- レートリミットに注意（リクエスト間隔を空ける）
- ヒストリカルデータの初回取得は時間がかかる
